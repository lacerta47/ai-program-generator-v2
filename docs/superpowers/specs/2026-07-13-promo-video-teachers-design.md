# 교사 대상 소개/홍보 영상 — 설계

2026-07-13 · 브레인스토밍 확정본

## 목적·요구사항

- **용도**: 교사 연수·설명회에서 상영하는 "AI 프로그램 생성기" 소개 영상.
- **길이**: 90초~2분 (목표 약 105초).
- **핵심 메시지 3개** (이 순서로 서사 구성):
  1. 아이가 혼자 해낸다 — 저학년 아이가 어른 도움 없이 한국어 계획서만으로 첫 프로그램을 만든다.
  2. 교육적으로 설계됐다 — 역할 카드·개념 칩·학습 메타 등 수업 도구로서의 설계.
  3. 수업에 바로 쓸 수 있다 — 교사 계정 발급 → 학번·PIN 학생 로그인 → 학급 보드 공유 플로우가 준비됨.
- **내레이션**: Edge TTS `ko-KR-SunHiNeural` (차분한 여성 톤). 선생님께 말하는 "~합니다" 체.
- **자막**: 내레이션 전문을 하단 번인(ASS), 핵심 키워드는 중앙 타이틀 카드로 반복.
- **BGM**: 사용자가 무료 음원 파일을 제공 → 믹싱 시 내레이션 구간 자동 덕킹(-12dB).
- **데모**: 실제 계획서 작성→Gemini 생성 과정을 라이브로 캡처 (대기 구간은 배속 편집).

## 스토리보드 (총 ~105초)

| # | 장면 | 시간 | 내용 | 제작 방식 |
|---|---|---|---|---|
| 1 | 인트로 | 0–8s | 앱 무드 모션 그래픽. 타이틀 "계획서를 쓰면, 프로그램이 됩니다" | HTML 모션 |
| 2 | 컨셉 | 8–20s | "코딩을 몰라도 괜찮아요. 아이는 한국어로 계획서만 씁니다" + 계획서 폼 첫 등장 | 모션+캡처 |
| 3 | 라이브 데모 | 20–55s | 아이 시점: 계획서 타이핑 → 생성 로딩(BuilderBot) → 미리보기 조작 → 수정 요청. 메시지① | 라이브 캡처(배속) |
| 4 | 교육적 설계 | 55–75s | 역할 카드·개념 칩·학습 메타 화면 + "왜 그렇게 움직이는지 배웁니다". 메시지② | 캡처+오버레이 |
| 5 | 교실 도입 | 75–95s | 교사 시점: 학번 계정 발급 → 학생 로그인(학교+학번+PIN) → 학급 보드 공유. 안전장치는 자막 한 줄. 메시지③ | 라이브 캡처 |
| 6 | 아웃트로 | 95–105s | 로고 + 사이트 주소 + 한 줄 카피 | HTML 모션 |

감정 흐름: "신기하다 → 진지한 도구네 → 우리 반에서 바로 되겠네".

## 제작 파이프라인 (A안: 하이브리드)

작업 폴더 `ai-program-generator/promo/`. 산출물 mp4·프레임·음성 파일은 gitignore.

### (a) 모션 그래픽 렌더러 — `promo/scenes/*.html`
- 장면별 독립 HTML. `globals.css` OKLCH 토큰 + Jua/Gowun Dodum 폰트 복사(오프라인 렌더 가능하게 로컬 폰트 또는 next/font 산출물 활용).
- 애니메이션은 `render(t)` 형태로 시간을 함수화 — 브라우저에서 t를 1/30초씩 진행하며 프레임 스크린샷 → ffmpeg로 30fps 영상화. 캡처 타이밍 비의존·결정적 렌더.

### (b) 라이브 데모 캡처 — Playwright
- 로컬 dev(3000) + 1920×1080 뷰포트. 계획서 타이핑(사람 속도), 생성, 미리보기 조작, 보드 공유, 교사 화면을 자동화.
- Playwright 비디오 녹화(webm) → 생성 대기 구간 ffmpeg 8~16배속.
- 데모 계정: selftest 패턴대로 시드 스크립트로 교사·학생 데모 계정 생성, 종료 시 정리.

### (c) 내레이션 — edge-tts (무료, 키 불필요)
- 장면별 mp3 개별 생성. 장면 길이를 내레이션 길이에 맞춰 조정(영상이 말을 따라감).

### (d) 자막 — ASS 포맷, ffmpeg 번인
- 하단 반투명 바탕+흰 글씨. 중앙 키워드 카드는 (a)에 포함.

### (e) 최종 합성 — ffmpeg
- 클립 concat → 내레이션 + BGM(덕킹) 믹스 → 자막 번인 → `promo-teachers-v1.mp4` (1080p H.264 30fps).

### 사전 설치
ffmpeg(winget), edge-tts(pip), Playwright(없으면 promo 로컬 설치). 진행 중 없는 것만 설치.

## 검증 계획

- 장면 클립 제작마다 스크린샷/구간 샘플로 중간 컨펌.
- 최종 합성 전 전 장면 무음 시사본 1회 컨펌.
- 내레이션 mp3는 대본 텍스트와 함께 제공해 어색한 발음 교정 라운드 1회.
