# 품질 개선 2차 재시험 준비

## 비교 대상

- 기준군: 1차 200건 시험의 개선 후 결과 100건과 당시 프롬프트·유형 가이드·검증기 스냅샷
- 후보군: 현재 작업 트리의 정밀 게이트와 보강된 유형 가이드
- 기획: 1차 시험의 고정 기획 100개를 그대로 재사용
- 새 AI 요청: 후보군 100건만 생성. 기준군은 저장된 결과를 재사용
- 출력: `.quality-eval-20260909-retest-v2/`

## 실행 명령

```powershell
.\scripts\run-quality-retest.ps1
```

스크립트는 다음을 순서대로 수행한다.

1. 기존 개선 후 결과를 새 출력 폴더의 `before` 기준군으로 준비
2. 현재 프롬프트·가이드로 `after` 후보군 100건 생성
3. 격리된 브라우저에서 모든 반환 결과 조작 검사
4. 음악·수족관 버튼 반복 클릭 검사
5. 미로 BFS 경로 계산, 방향키·화면 버튼 자동 이동, 출구 도달·승리 표시 기록
6. `summary.json` 집계

중간에 중단되어도 이미 생성된 JSON을 재사용하므로 같은 명령으로 이어서 실행할 수 있다. 생성물은 Firestore에 게시하지 않으며 외부 네트워크를 차단한다.

## 사전 성공 기준

- 전체 엄격 성공률: 기존 86%보다 상승, 목표 90% 이상
- 게이트 미탐: 기존 5건보다 감소, 목표 2건 이하
- 정상 실행 과잉 차단: 기존 2건에서 0건
- 음악: 15건 중 14건 이상 엄격 성공, 반복 재생 오류 0건
- 수족관: 15건 중 14건 이상 엄격 성공, Canvas CSS 변수 직접 사용 0건
- 미로: 생성 가능한 모든 격자에서 BFS 경로 존재, 시작 전 입력 오류 0건, 자동 이동 결과는 지원률·출구 도달률을 별도 보고

생성 API 오류는 프롬프트 품질과 분리해 집계한다. 자동 완주는 내부 상태 이름이나 필수 아이템 규칙이 프로그램마다 달라 지원하지 못하는 결과가 있을 수 있으므로, 미지원과 실제 이동 실패를 구분한다.

## 준비 검증 결과

- 새 게이트를 1차 개선 후 반환 코드 97건에 다시 적용: 차단 6건, 실행 오류 미탐 3건, 정상 실행 과잉 차단 0건
- 기존 `btoa` 과잉 차단 2건은 모두 통과
- 기존 Canvas CSS 변수 오류 1건과 SVG 삭제 후 재참조 오류 1건은 새 게이트가 차단
- 확장 하네스를 기존 결과에 실행: 오디오 반복 클릭 630회, 미로 내부 격자 자동 해석 18건, 경로 발견 18건, 실제 출구 도달 3건
- 단위 테스트와 타입 검사 통과 후 재시험 폴더 준비 완료
