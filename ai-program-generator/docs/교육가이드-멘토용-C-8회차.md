# LUN 수업 가이드 · C안 — 8회차 "몸으로 먼저, 고치고, 함께 만들기" (v2.3)

**누가 읽나** 처음 가르치는 사람. 메인 교사(전체 진행)와 보조 교사(고등학생 멘토 가능) **두 명**이 이 문서 하나로 같은 수업을 합니다.
**누구에게** 초등 1~3학년 **한 학급 20명**(학년 섞임). 컴퓨터실, 1인 1기기(7회차는 팀당 1기기), 프로젝터 1대.
**얼마나** 45분 × 8회 (한 학기 격주 또는 방과후 8주). 회차마다 새 개념은 **하나**만.
**도구** LUN(eduai-lun.co.kr). 학생 계정은 담당 교사가 미리 발급.

> 20명 교실을 분 단위로 5회 시뮬레이션해 고친 판입니다(`교육가이드-시뮬레이션-기록.md`).

**B안(6회차)과 무엇이 다른가** — 앞 4회 + 6회차(우리 말로 만들기)는 같은 뼈대. C안은 세 가지가 더 있습니다.
1. **5회차 고치기 탐정** — "지금은 이래요 / 이렇게 되면 좋겠어요" 두 칸을 짝 탐정 2라운드로.
2. **7회차 우리 팀 작품** — 3명이 기기 하나로, 합의가 아니라 **배분**(먼저/그다음/만약 칸을 한 사람 한 칸)으로 만든다.
3. 개념이 4회에 다 나온 뒤 **4회를 더 돌려 정착**. 6회차형이 "만난다"면 8회차형은 "쓴다"까지.

## 0. 노선

```
   몸으로 먼저 (전체 놀이 5분)  →  화면에서 확인 (짝과 만들기)  →  내 작품에서 찾기 (배지)
```
- 1~2학년은 몸이 화면보다 빠릅니다. 설명 대신 놀이 → 화면에서 "아까 그거네".
- 놀이는 20명이 자리에서 한꺼번에.
- 개념은 배지 다섯 글자만: **`순서` `입력` `출력` `반복` `조건`.** 알고리즘·변수·함수·코딩·디버깅은 어른도 안 씁니다(5회차도 '탐정').

## 1. 교실 운영 체제 — 20명을 두 명이

### 역할
| | 메인 교사 | 보조 교사 |
|---|---|---|
| 위치 | 프로젝터 앞 | 뒤에서 순회 |
| 하는 일 | 시범, 전체 신호, **시간**, 몸놀이 | **① 실패 기기 → ② 느린 3명 → ③ 명단 체크표** (이 순서) |
| 안 하는 일 | 개별 기기 붙잡기 | 전체를 향해 말하기 |

### 짝 체제
- **3학년+1학년 / 2학년+2학년** 고정 짝, 짝표 자리 부착. 역할: **읽는·적는 사람** / **말하는·확인하는 사람**. 2학년 짝은 회차마다 교대. 결석 시 이웃 짝에 붙여 3인조.
- **7회차 팀** = 짝 둘을 합쳐 3~4명이 아니라, 담당 교사가 **3명 팀 6개 + 2명 팀 1개**를 미리 짭니다(각 팀에 3학년 1명 이상). 팀표는 6회차에 배부.

### 신호
- **주목** "**로봇 정지!**" → 손 머리. 매 회차 첫머리 1회 연습.
- **진행** "골랐으면 손 머리" → 80%면 다음.
- **다 한 사람 카드** 칠판 옆 회차별 고치기 미션 3개. 돌아다니지 않기.

### 확인 신호
전원 = 짝에게 말하기. 표본 = 보조가 회차당 **5명** 듣고 **명단 체크표**(부록 E). 8회면 전원 2회.

### 선처리 (보조, 10분 전) — 부록 F
20대 로그인 · **소리 끄기** · 탭 하나 · 예비 작품 · 칠판(고치기 문장·다 한 사람 카드). **아이는 로그인하지 않습니다.**

### 쿼터
학생 **일일 한도 4**, 교사 풀 **560 이상**(20 × 3 × 8 + 여유).

## 1회차 — 순서

**한눈에** `순서` · `소개·인사 카드` · 카드 1

### 선처리 추가분
짝표 · 프로젝터 `골라서 만들기` · 칠판 카드 ①배경 색 바꿔 줘 ②글자 크게 ③내 이름 넣어 줘

### 진행표
| 분 | 단계 | 메인 | 보조 |
|---|---|---|---|
| 0~3 | 열기 + "로봇 정지" 연습 | 전체 | 손 머리 시범 |
| 3~9 | 몸놀이 — 반 전체 로봇 | 진행 | 참여 |
| 9~23 | 카드 만들기(동기화) | 신호 | 순회·실패 |
| 23~31 | 찾기 — 짝에게 ① 짚기 | 🧩 시범 | 표본 5 |
| 31~37 | 서로 보기 | 시간 | 순회 |
| 37~41 | 정리·신호 | 전체 | 체크표 |

### 단계별
- **열기**: "오늘은 **컴퓨터한테 순서대로 시키는 것**. 신호 하나 — '**로봇 정지!**' 하면 손 머리!" (2회) "옆 친구가 짝. 짝이 읽어 주고 대신 쳐 줘요."
- **몸놀이(자리에서)**: "여러분 전부 로봇. **손 들기 → 박수 → 앉기.**" 한 번 → **순서 바꿔** "앉기 → 박수 → 손 들기." **"똑같은 셋인데 순서가 바뀌니 다르죠?"** 아이 셋이 앞에서 명령 하나씩, 손가락 1·2·3. **"로봇은 시키는 차례대로만. 이걸 '순서'."**
- **만들기(동기화)**: `골라서 만들기` → **`소개·인사 카드`**. 메인: **"질문은 짝이 읽어요. 하나 골랐으면 손 머리!"** 메인은 **선택지를 읽지 않음**(20명이 똑같이 고름), 자기 화면은 🎲로. 이름 칸 → `다음`. 대기: **"여러분이 고른 차례대로 만들고 있어요."** 보조: 1분↑ → `새로 만들기` → 예비 카드.
- **찾기**: 메인이 🧩 ①②③ 짚으며 읽기 → **"짝에게 ①이 어디인지 눌러서 보여 주세요."** 역할 바꿔 한 번 더. 배지: **"'순서' — 몸으로 한 거랑 같은 이름."** 보조 표본 5.
- **서로 보기**: 다른 짝 화면 하나. **"고른 게 다르면 순서 속 내용이 달라져요."**
- **정리·신호**: **"짝에게: '먼저 ○○, 그다음 ○○.'"** 전원 30초.

### 하지 말 것
몸놀이 전 설명 · 메인이 선택지 읽기 · 타일 다 보여 주기 · 대신 누르기

### 막힐 때
| 상황 | 하기 |
|---|---|
| 로그인 풀림 | 명단 PIN 재로그인 → 짝 기기 |
| 생성 1분↑ | `새로 만들기` → 예비 |
| 결과 이상 | "오, 고칠 거리!" → 카드 ② |

## 2회차 — 입력·출력

**한눈에** `입력` `출력` · `칭찬·운세 뽑기`(대안 룰렛) + 고치기 맛보기 1칸 · 작품 1

### 선처리 추가분
칠판 고치기 **"버튼을 크고 노란색으로 해 줘"** · 카드 ①메시지 세 개 더 ②버튼 이름 '눌러 봐' ③배경 밤하늘

### 진행표
| 분 | 단계 | 메인 | 보조 |
|---|---|---|---|
| 0~3 | 열기 — "지난주 이름?" | 전체 | 재배치 |
| 3~9 | 박수 치면 앉기 | 진행 | 참여 |
| 9~21 | 뽑기 만들기 | 신호 | 순회·실패 |
| 21~29 | 찾기 — 입력·출력 짚기 | 시범 | 표본 5 |
| 29~37 | 고치기 맛보기(1칸, 칠판 베끼기) | 시범 | 1학년 짝 확인 |
| 37~41 | 정리·신호 | 전체 | 체크표 |

### 단계별
- **몸놀이**: **"박수 한 번이면 앉기, 두 번이면 손 들기."** 5회 → 아이가 박수. **"박수는 내가 알려주는 것 — 입력. 앉는 건 컴퓨터가 보여 주는 것 — 출력. 입력 없으면?"** "아무 일도."
- **만들기**: **`칭찬·운세 뽑기`** 동기화. 완성: **"버튼 눌러 봐요. 누르는 게 입력! 나온 글자는 출력!"**
- **찾기**: **"짝에게 '입력이 어디야?' — 버튼 짚기. '출력은?' — 글자 짚기."**
- **고치기 맛보기**: 프로젝터로 `이렇게 되면 좋겠어요`에 칠판 문장 치는 시범 → 베끼기(짝이 쳐도 됨) → `무엇이 바뀌었을까요?` → **"뭐가 바뀌었어요? 짝에게 짚어 보여요."** (`지금은 이래요` 칸은 5회차에)
- **정리·신호**: **"내가 누르면(입력) ○○이 나와요(출력)"**. 1학년은 하나 짚기.

### 하지 말 것
문장 두 개 · 사전 뜻 설명 · 소리 켜기

### 막힐 때
| 상황 | 하기 |
|---|---|
| 안 바뀜 | "버튼 노란색" 짧게 |
| 망가짐 | "버튼 원래대로 해 줘" |
| 실패 | `새로 만들기` → 예비 뽑기 |

## 3회차 — 반복

**한눈에** `반복` · `시계·타이머`(대안 수족관) + 1회차 카드 비교 · 작품 1

### 선처리 추가분
프로젝터에 메인의 1회차 카드 + 예비 시계 · 칠판 고치기 **"숫자가 바뀔 때마다 색깔도 바뀌게 해 줘"** · 카드 ①물고기 세 마리 더 ②'째깍' 글자 ③배경 천천히 어둡게

### 진행표
| 분 | 단계 | 메인 | 보조 |
|---|---|---|---|
| 0~3 | 열기 | 전체 | 재배치 |
| 3~9 | 열 번 대신 한마디 | 로봇 역 | 참여 |
| 9~23 | 시계 만들기 | 신호 | 순회·실패 |
| 23~31 | 찾기 + **카드 비교** | 프로젝터 나란히 | 표본 5 |
| 31~37 | 고치기 | 시범 | 순회 |
| 37~41 | 정리·신호 | 전체 | 체크표 |

### 단계별
- **몸놀이**: 메인이 로봇. **"나한테 박수 열 번 치게 해 보세요. '박수' 열 번!"** (힘듦) → **"박수 열 번 반복!"** → 즉시. **"컴퓨터한테는 '반복' 한마디. 같은 일을 여러 번. 계속은? 계속 반복! 시계처럼."**

## 5회차 — 고치기 탐정: 두 칸으로 말하기

**한눈에** 새 개념 없음 · 고치기 **두 칸** · **짝 탐정 2라운드** · 고친 작품 1

## 6회차 — 우리 말로 만들기: 짝 계획서 하나

## 7회차 — 우리 팀 작품: 합의 대신 배분

**한눈에** 협력 · `만들기` 4칸 **팀당 기기 1대** · 팀 작품 1 · **+ 개인 갤러리 워크 8′**(8회차 부담 분산)
**팀** 3명 × 6 + 2명 × 1 (담당 교사가 미리, 각 팀 3학년 1명 이상). 역할: **말하는 사람 · 적는 사람 · 확인하는 사람**.
**핵심 장치 — 합의 종이(부록 H)**: 칸이 **세 개뿐**(먼저 / 그다음 / 만약) + 각 칸 옆 이름 칸. 규칙 "**한 사람 한 칸**". 합의가 아니라 배분이라 다툴 게 줄어듭니다. 3분 모래시계, 못 정하면 가위바위보.

### 선처리 추가분
- 팀별 기기 1대만 켬(나머지 13대 끔) · 합의 종이 7장 · 모래시계(또는 프로젝터 타이머 3분) · 프로젝터에 팀 작품 예시("먼저 동물 퀴즈 3문제 → 그다음 다 맞히면 룰렛 → 만약 틀리면 힌트") · **예측 카드**(우리 것 중 뭐가 제일 먼저 나올까 ○) 7장
- 카드 ①"③에 만약 하나 더" ②"제목에 팀 이름" ③"색 하나 더"

### 진행표
| 분 | 단계 | 메인 | 보조 |
|---|---|---|---|
| 0~3 | 열기 — 팀·역할 발표 | 전체 | 팀 자리 |
| 3~8 | 한 목소리 놀이 | 진행 | 참여 |
| 8~14 | **배분** — 합의 종이 3분 + 이름 | "지금 몇 번째 칸?" 1분마다 | 다투는 팀만 |
| 14~26 | 4칸 → 만들기 | 칸 신호 | 순회·실패 |
| 26~31 | 확인 ○△ + 두 칸 고치기 1회 → `수정 저장` | 시범 | 순회 |
| 31~39 | **개인 갤러리 워크**(6회차 작품, 4′×2교대) | 교대 신호 | 무서워하는 아이 |
| 39~43 | 정리·신호 | 전체 | 체크표 |

### 단계별
- **몸놀이 — 한 목소리**: 팀이 로봇(메인)에게 명령 3개, **한 사람 한 개**. 순서를 팀이 정함("누가 먼저?"). 다투면 메인: **"먼저 ○○ 거, 그다음 △△ 거 — 순서. 둘 다 들어가요."** 그다음 "만약": **"만약 로봇이 손 들면 ○○ 명령, 아니면 △△."** **"팀 작품은 누구 게 이기냐가 아니라 어떤 순서로 넣느냐."**
- **배분 (6′, 기기 끔)**: 합의 종이. **"칸이 세 개. 한 사람 한 칸. 먼저 칸은 누구? 그다음은? 만약은? 3분!"** 각 칸에 내용 + 이름. 메인 1분마다 "지금 몇 번째 칸?". 3분 후 못 정한 팀은 가위바위보(보조). 2명 팀은 한 사람이 두 칸.
- **4칸 → 만들기 (12′)**: 적는 사람 계정. 메인이 칸 이름 부르며 진행(`프로그램 이름`=팀 이름 → 생김새 → 사용법 → ①②③=합의 종이 옮기기). 말하는 사람이 읽어 주고 적는 사람이 침(1학년이 적는 사람이면 확인하는 사람과 교대). 생성 대기 30초: **확인하는 사람은 예측 카드 ○, 말하는 사람은 발표 첫 문장 연습** (놀지 않게).
- **확인 + 고치기 1회**: 확인하는 사람이 합의 종이 ↔ 화면 ○△. △ 하나만 두 칸으로 고치기. **`수정 저장`**. 게시는 다음 시간.
- **개인 갤러리 워크 (8′)**: 팀 기기는 그대로, 나머지 기기 켜서 각자 `게시판` 우리 반의 **6회차 짝 작품** 열기. 창가 줄 설명 / 복도 줄 이동, 질문 카드 **"어디가 만약이야?"** 답 들어야 좋아요. 4분 교대.
- **정리·신호**: **"우리 팀 건 먼저 ○○(누구 거), 그다음 △△(누구 거)"** 아무나 한 명, 나머지 끄덕. 3학년 팀은 "만약"까지. "다음 시간 팀 발표는 세 명이 한 문장씩."

### 하지 말 것
팀원마다 기기 · 역할을 아이가 정하게 · 잘하는 아이가 다 하게(역할 종이를 보이게)

### 막힐 때

## 8회차 — 자랑하기: 팀 발표 · 도감 · 수료

**한눈에** `게시판에 올리기`(팀) · 팀 발표 7 × 1.5′ · `개념 도감` · 수료 · 게시 2(6회차 짝 1 + 팀 1)
**보호자 공유는 알림장으로**(부록 G). 교실에서 `공유하기`는 1분 시연만.

### 선처리 추가분
메인: `관람 PIN` 확인·알림장 문구 · 칠판 "팀 발표 세 문장: 이름 / 먼저·그다음 / 만약" · 발표 순서 7팀 · 별명 규칙

### 진행표
| 분 | 단계 | 메인 | 보조 |
|---|---|---|---|
| 0~3 | 열기 | 전체 | 팀 자리 |
| 3~8 | 세 문장 연습(팀 안에서 역할별 한 문장) | 진행 | 순회 |
| 8~15 | 팀 작품 올리기(적는 사람 계정, 작성자에 팀원 별명 전부) + 6회차 짝 작품 확인 | 시범 | "쓸 수 없는 말" 처리 |
| 15~28 | 팀 발표 7 × 1.5′ (모두 자기 화면에서 그 작품 열고 듣기 → 좋아요) | 시간·박수로 끊기 | 무서워하는 아이 옆 |
| 28~31 | `공유하기` 시연 1′ + 알림장 예고 | 프로젝터 | |
| 31~38 | `개념 도감` 5 + (시간 남으면) 팀 작품 `더 키우기`로 내 계정에 복사 | 시범 | 표본 5·체크표 마감 |
| 38~43 | 수료 | 전체 | |

### 단계별
- **세 문장**: 팀 안에서 이름 / 먼저·그다음 / 만약 — 한 사람 한 문장. 1학년은 이름 문장.
- **올리기**: 적는 사람 계정 `내 작품` → 팀 작품 → **`게시판에 올리기`** → 우리 반 → 제목=팀 이름, 작성자 이름 **"민지·서준·하늘"**. "쓸 수 없는 말이에요" → 문구의 그 말만 바꿈.
- **팀 발표**: **"발표 팀 작품을 모두 자기 화면에서 열고 들어요. 끝나면 좋아요!"** 1.5분 넘기면 박수로 끊기. 빠진 문장은 "만약~은?" 한 단어만.
- **공유하기 시연**: **"이게 QR. 집에는 선생님이 알림장으로 주소를 보내요."**
- **도감**: **"다섯 개 다? 짝에게 짚으면서 이름."** 남는 시간: 팀원 각자 게시판에서 팀 작품 → `더 키우기` → 자기 계정에 저장(도감에 남기기, 선택).
- **수료**: **확인 신호: 도감 5 짚으며 이름 + 팀 작품에서 '먼저·그다음' 한 문장.** **"이제 순서대로 시키고, 말 걸고, 반복시키고, 만약을 넣고, 안 되면 두 마디로 고치고, 친구랑 합쳐서 만들 줄 알아요."**

### 하지 말 것
좋아요 순위 · 1.5분 초과 · 팀 발표를 한 아이가 다
