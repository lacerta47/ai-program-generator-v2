# 유형별 모델 배정 후속 계획

등록일: 2026-10-31. 일정 미정, 후속 작업으로 보류.

수업 동시 생성에 대한 호출 경로 분산은 별도 [호출 분리 계획](provider-split-plan-2026-10-31.md)을 따른다. 모델 품질별 배정과 호출 용량 분산은 독립적으로 검토한다.

현재는 사용자 생성에서 기존 Gemini 3.8 Flash / 4 Argon 배정을 유지하고 BizRouter 키로 호출한다. 자동 예시는 기존 무료 Gemini 경로를 유지한다.

후속 작업:

1. 퀴즈의 폼 제출 차단 문제를 프롬프트와 동작 검사에 반영하고 승인받은 생성으로 재확인한다.
2. 유형별 직접 실행 평가와 비용을 비교해 모델을 배정한다. 가격만으로 우열을 결정하지 않는다.
3. Opus 5.5는 사용자 평가에서 전반적인 품질이 좋았으므로 복잡 유형 후보로 검토한다. Luna·Haiku·Sol·Sonnet·Terra는 확인된 결함과 유형별 품질을 다시 확인한다.
4. 후보 배정표와 예상 수업 비용을 검토한 뒤 운영 적용을 결정한다. 실제 생성 시험 및 커밋·푸시는 사용자 승인을 받는다.

기존 시험 결과와 직접 평가는 `output/bizrouter-model-eval-20261030/`에 보관한다.
