## 구현 순서와 정책

1. 서버에서 유형·게임 장르·신규/수정·사진 여부로 생성 정책을 정한다. 클라이언트가 모델 ID나 최대 출력 토큰을 직접 지정하지 못하게 한다. 알 수 없는 유형/장르는 현재 기본 정책으로 처리한다. 직접 만들기는 서버에 구조화된 유형이 없으므로 우선 기존 Gemini 배정을 유지한다.
2. `lib/ai/modelPolicy.ts`에 정책과 검사를 모으고, provider.ts에서 허용 모델·경로를 결정한다. `lib/ai/types.ts` 계약을 통해 전달하며 BizRouter가 임의로 클라이언트 모델명을 받아 호출하지 않게 한다. 현재 requireSplitConfig의 Gemini 두 모델 고정 검증도 함께 수정한다. 표에 있는 모델 문자열을 환경변수에 바꾸는 것만으로 적용할 수는 없다.
3. BizRouter 전체 10개 슬롯을 유지한다. 새 모델마다 10개 슬롯을 추가하지 않는다. Opus를 선택했는데 BizRouter가 포화인 경우에는 우선 대기를 추천한다. Argon으로 자동 대체하면 품질이 달라지므로 별도 비교와 운영 결정을 거친다. Haiku의 Gemini 3.8 대체도 비용·품질 검증 후 명시적으로 허용한다. 실행 중 오류를 다른 모델에서 자동 재생성하지 않는다.
4. 신규 생성부터 확인한 뒤 수정 경로를 검증한다. 수정은 원래 생성 모델 유지가 기본 후보다. 과거 작품의 모델이 불명확하면 현재 Gemini 정책으로 처리한다. 서버가 정한 모델/경로/정책 버전과 토큰을 기록하고, 게시물에 추가할 필드는 서버 검증·Firestore allowlist/rules와 함께 검토한다.
5. 사진 입력은 기존 검증된 Gemini 경로부터 유지한다. 각 후보의 이미지·엄격한 JSON 스키마·SSE 스트리밍·교육 메타 호환을 검사한 뒤 확대한다. 모델 변경에 맞춰 화면·프롬프트·한도 의미를 조용히 변경하지 않는다.

## 승인 후 비교 시험안

먼저 모의 검사를 수행한다. 12유형·12게임 장르 배정, 알 수 없는 값, 임의 모델명 주입, 키별 5개·전체 10개 상한, 대기·취소·환불, 모델 오류 비재생성, 수정 및 사진 정책을 검증한다.

실제 생성은 새 승인을 받은 뒤 아래 60회부터 제안한다. 앞선 운영 점검의 2회 승인을 이 시험에 재사용하지 않는다.

| 비교 | 계획 |
|---|---|
| 카드·운세·계산기·시계 | 4유형 × 3개 동일 입력 × Haiku/Flash = 24회 |
| 미로·꾸미기·수족관 | 3유형 × 3개 동일 입력 × Opus/Argon = 18회 |
| 블록 쌓기·블록 깨기·숫자 합치기 | 3장르 × 3개 동일 입력 × Opus/Flash = 18회 |
| 합계 | 60회. 그림판은 2차 비교 후보 |

각 쌍은 같은 선택지·프롬프트 버전·참고 예시·출력 제한 조건을 사용하고 차이를 기록한다. 실제 수업용 디자인 프리셋과 선택 색상을 포함한다. 현재 운영에서 관찰된 빈 미리보기는 원인이 확인되지 않았으므로, 비교 시험 전에 실행 환경이 실제 렌더링되는지 확인한다. 서버 200이나 코드 게이트 통과만으로 모델의 화면 품질을 채점하지 않는다.

판정은 핵심 기능(시작/정답/종료/초기화), 390px 모바일 조작, 한글 표현, 디자인, 1회·성공 1건당 비용, 완료 시간으로 나눈다. 첫 3개 표본의 통과는 확대 시험 진입 근거이며 안정적 성공률의 증명은 아니다. 저가 유형은 현재 모델과 조작·디자인 품질이 동등한지, 고급 유형은 추가 비용만큼 직접 평가가 나아지는지를 확인한다. 실패하거나 차이가 작으면 현재 배정을 유지한다.

## 2026-11-04 비용 재검토: Opus 기본 후보 보류

사용자가 Opus 비용이 높다고 지적해 우선순위를 재검토했다. 위 Opus 비교안은 최초 후보 기록이며, 다음 비용 검토를 반영해 시험 구성을 다시 확정한다.

2026-11-04 Anthropic 공식 가격표의 입력/출력 100만 토큰당 기본 단가는 Opus 5.5 $4/$20, Opus 5·4.8·4.7·4.6·4.5 $5/$25다. 구버전 Opus는 동일 토큰에서 25% 더 비싸므로 단순 버전 하향을 절감안으로 추천하지 않는다. Sonnet 5.5·5는 $2/$10으로 Opus 5.5의 절반이며, Sonnet 4.6·4.5는 $3/$15로 Sonnet 최신 계열보다 비싸다. 기존 2026-10-30 BizRouter 키별 모델 목록의 단가도 같은 관계였다. 실제 적용 전 BizRouter 현재 키별 가격·접근 가능 여부는 다시 확인한다.
