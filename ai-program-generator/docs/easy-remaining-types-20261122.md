- 기존 생성물은 유형별 1개를 재생했습니다. 일반 실행·배치 검사에서 7개는 오류 없이 끝났습니다. 기존 13건반 피아노는 390px에서 건반 5개에 가로 스크롤로 접근해야 했습니다. 새 검사 표식이 없던 7개는 핵심 조작 미검증으로 남겼고, 꾸미기 1개는 두 폭에서 무대 표시를 확인했습니다.
- 격리 없이 연 Edge 시험에서는 같은 PNG 버튼의 파일 수신이 성공했습니다. 운영과 같은 `sandbox allow-scripts`에서는 파일 수신이 차단됐습니다. 새 프롬프트는 미리보기에서 실제 PNG를 화면에 표시하고, 별도로 연 작품 HTML에서는 파일 저장을 지원하도록 요청합니다.
- Claude Opus 5.5가 기준 커밋과 변경 제안을 검토했습니다. 운세·카드·소리놀이·꾸미기·시계의 추가 충돌과 오래된 검사 오탐을 반영했습니다. 로컬 구현은 Codex가 직접 검증했습니다. [검토 답신](ai-bridge/archive/claude/2026-11-22-easy-remaining-types.md)
- 이번 작업은 로컬 검증까지 완료했습니다. 새 프롬프트로 실제 모델이 반환하는 결과물과 생성 성공률은 별도 생성 시험이 필요합니다.

## 13건반 피아노·LED 계산기 최종 생성 확인

보완한 지침과 이전과 동일한 선택지로 Gemini 3.8 Flash에 두 조합을 한 번씩 요청했습니다. 호출 2회, 재시도 0회, 응답과 정적 검사 2/2입니다. 생성된 원본 코드를 그대로 실행했고, 두 모바일 폭에서 총 4/4회 통과했습니다.

| 조합 | 360px | 390px |
|---|---|---|
| `sound-02` · 13건반 피아노 | 최소 74.5×64px, 13개 모두 가로 잘림 없이 표시 | 최소 82×64px, 13개 모두 가로 잘림 없이 표시 |
| `calc-05` · LED 계산기 | 8% = 0.08, 8×2 = 16. LED 숫자·결과 텍스트·브라우저 접근성 트리 일치 | 같은 두 계산의 LED 숫자·결과 텍스트·브라우저 접근성 트리 일치 |

피아노는 자유 연주와 따라치기에서 각각 건반을 측정했습니다. 두 폭에서 소리가 나고 ‘생일 축하’ 25음을 따라쳐 최종 250점을 확인했습니다. 계산기는 곱하기·퍼센트만 제공하며, 결과 텍스트를 `aria-live="polite"` 안에서 갱신합니다. 접근성 트리 노출을 Edge에서 확인했습니다.

기존 품질 비교 도구의 사전 검사도 추가 호출 없이 통과했습니다. 사전 검사에서 읽은 지침과 두 생성 요청 당시의 지침은 같은 문자열입니다.

직접 모델 호출과 터치 모바일 에뮬레이션으로 확인했습니다. 운영 DB를 사용하는 시험은 범위에 포함하지 않았습니다. 원본과 캡처는 작업 워크트리의 `out/easy-remaining-final-20261122/results/`에 있습니다. [Issue #196](https://github.com/lacerta47/ai-program-generator-v2/issues/196)
