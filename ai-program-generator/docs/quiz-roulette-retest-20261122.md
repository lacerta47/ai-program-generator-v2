수학·직접 입력 퀴즈는 진단용 복사본에 `[hidden] { display: none !important; }` 한 줄을 붙여 둘 다 통과했고, 10초 퀴즈는 시간 종료까지 통과했다. 원인 확인용 결과이며 7/10에 반영하지 않았다. 남은 작업은 숨김 상태와 CSS 표시 우선순위를 일치시키고, 회전음과 당첨음을 해당 선택에만 연결하는 것이다.

이전 입력 40,003·출력 44,020·추론 1,161토큰, 평균 30.8초. 새 입력 41,911·출력 39,882·추론 1,309토큰, 평균 29.9초. 모델·선택이 같은 비교지만 조합당 표본은 각각 한 건이다.

새 증거는 무시되는 `out/quiz-roulette-retest-20261122/results/`에 있다. 별도 `css-diagnostic/`과 `names-replay/`에 추가 검증을 저장했다. 이번에는 승인된 10번만 호출했으며 배포하거나 작품을 게시하지 않았다.

## 실패했던 3건 재생성

퀴즈 가이드에 `[hidden] { display: none !important; }`를 명시하고, 결과·다음·종료 영역을 필요한 단계에서만 표시하도록 했다. 룰렛은 실제 `stopfx` 선택에서 `cheer` 여부를 읽어 당첨 소리 켜기/끄기를 명시적으로 전달한다. 회전음과 시각 효과는 각 선택을 따르게 했다.

같은 모델과 선택지로 승인된 3건만 다시 생성했다. 생성 원본은 수정하지 않았다.

| 조합 | 판정 |
|---|---|
| 10초 제한 수학 | 시작 시 종료 화면 숨김, 3문항의 채점·정답 설명·종료·다시하기·시간 초과 통과 |
| 뺄셈 직접 입력 | 빈 답 안내, 클릭·Enter 채점, 정답과 설명, 3문항 뒤 종료와 다시하기 통과 |
| 간식 8칸 룰렛 | 일반·동작 줄이기에서 포인터와 결과 일치. 회전 중 소리 시작 19회, 당첨 결과 표시 후 0회. 당첨 범례 강조 유지 |

3/3 통과로 이번 표의 기존 통과 조합 7개와 합쳐 10개 조합 모두 통과 사례가 확보됐다. 마지막 지침으로 10개를 한 번에 생성한 집계는 아니다. 원본 JSON·브라우저 증거는 `out/quiz-roulette-failures-20261122/results/`에 보관했다.

단위 249건 통과(기존 opt-in 2건 제외), API 67건 통과, 타입 검사·린트·프로덕션 빌드 통과. [Claude 가이드 검토](ai-bridge/archive/claude/2026-11-22-quiz-hidden-roulette-audio.md)는 기준 커밋과 전달한 변경 요약을 검토했고, Codex가 실제 생성 결과를 실행했다.
