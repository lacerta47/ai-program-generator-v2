# 생성 100건 재시험 평가 (2026-09-10)

## 결론

현재 후보를 그대로 적용하는 것은 보류한다. 이전 개선판의 엄격 성공률은 86/100이었으나 새 후보는 74/100으로 12%p 하락했다. 같은 100개 계획을 짝지어 비교했을 때 이전판만 성공한 경우가 20건, 새 후보만 성공한 경우가 8건이며 정확 이항검정의 양측 p값은 0.0357이다. 이번 표본에서는 새 후보의 하락을 단순한 생성 변동으로만 보기 어렵다.

정적 검증 규칙 개선은 효과가 확인됐다. 반면 유형 가이드 확장은 일부 유형에만 이득이 있었고 수족관과 소리 유형은 악화됐다. 따라서 검증기 변경은 유지하고, 새 유형 가이드는 축약·분리한 뒤 다시 소규모 시험하는 것이 적절하다.

## 시험 범위와 판정 기준

- 새 AI 생성: 100건
- 비교 기준: 직전 200건 비교 시험에서 생성한 개선판 100건을 재사용
- 입력: 유형과 소재가 같은 100개 계획
- 브라우저 검사: 생성된 190건 모두 기본 검사와 확장 동작 검사 완료
- 산출물: 결과 JSON 200개, 동작 검사 190개, 스크린샷 190개, `summary.json`
- 엄격 성공: 생성 성공 + 해당 버전 게이트 통과 + 기본/확장 브라우저 검사 무오류

재개 시 이미 저장된 결과는 건너뛰었으므로 오늘 추가 AI 생성은 없었다.

## 조치 1~5 효과 판정

### 1. `btoa` 검증 정밀화: 효과 확인

이전 검증기는 안전한 ASCII `btoa` 사용도 2건 차단했지만 실제 브라우저 검사는 정상 통과했다. 새 검증기는 이 2건을 허용했고, 새 후보의 `paint-13`에서도 구 검증기만 차단한 정상 결과를 새 검증기가 허용했다.

판정: 유지.

### 2. Canvas/SVG 정적 규칙: 효과 확인

새 검증기를 이전 결과에 다시 적용했을 때 다음 두 결함을 추가로 찾았다.

- Canvas 색상에 `var(--...)` 문자열을 직접 전달해 `addColorStop`이 실패한 수족관 1건
- 버튼의 `textContent`로 SVG를 지운 뒤 같은 SVG를 다시 조회한 그림판 1건

결과적으로 기존 정상 2건의 `btoa` 오탐을 제거하면서 실제 결함 2건을 새로 차단했다. 새 후보에서 게이트 오탐 후 브라우저 정상인 사례도 0건이었다.

판정: 유지. 단, 새 후보 런타임 실패 19건 중 8건은 여전히 미탐이므로 규칙 보강 여지가 있다.

### 3. 유형 가이드 확장: 부분 효과, 전체 승인 보류

- 그림판: 10/15 → 11/15, 게이트 미탐 2 → 1
- 미로: 11/15 → 11/15, 자동 분석 가능한 경로 9 → 11
- 소리: 14/15 → 12/15. 실행 가능한 결과의 반복 클릭은 안정적이었지만 문법 오류 3건 발생
- 수족관: 14/15 → 9/15. 잘못된 색상 계산, 정의 누락, 잘못된 RGBA 등 새 런타임 오류 발생

가이드가 길고 요구사항이 많아지면서 모델이 복잡한 결과를 만들거나 응답을 온전히 마무리하지 못했을 가능성이 있다. 이는 결과에 근거한 추정이며, 원인을 확정하려면 가이드 문장군을 나눈 A/B 시험이 필요하다.

판정: 그림판의 핵심 규칙은 남길 후보. 수족관·소리 가이드는 짧은 필수 규칙만 남기도록 축약. 미로는 성공률 개선이 없으므로 단계별로 분리 검증.

### 4. 반복 동작·미로 자동 검증: 관찰력 개선, 승리 판정은 보완 필요

- 이전 97개와 후보 93개, 총 190개 생성물에 확장 검사를 완료했다.
- 후보에서 버튼 반복 클릭 310회 중 290회가 자동 클릭 단계까지 성공했다.
- 후보 미로 11건에서 경로를 찾았으나 출구 도달은 2건, 화면의 승리 신호 확인은 0건이었다.

반복 클릭으로 상호작용 오류를 추가 발견한 점은 유효하다. 미로는 보물·열쇠 조건, 비동기 이동, 좌표 체계 차이 때문에 단순 최단 경로 실행만으로 승리를 확정하기 어렵다.

판정: 하네스 유지. 미로는 필수 아이템 경유와 상태 신호를 인식하도록 보완하기 전까지 `victorySignaled=0`을 곧바로 11건 모두의 제품 실패로 해석하지 않는다.

### 5. 재시험 실행 절차: 효과 확인

저장된 행을 재사용하고 누락된 동작 검사만 이어서 수행했으며 추가 생성 없이 완료됐다. 중단 후 재개와 결과 집계가 정상 동작했다.

판정: 유지.

## 주요 실패 형태

- 문법·응답 완결성: 잘린 `//` 주석, 잘못 닫힌 괄호, 잘못된 한글 토큰, 예상치 못한 입력 끝
- DOM/정의 누락: `Coral`, `pupul2`, `renderMinimap` 미정의, 없는 요소에 이벤트 연결
- 데이터 초기화: 존재하지 않는 배열의 `length` 접근, null 요소의 `textContent` 변경
- Canvas 색상: `rgb(NaN, NaN, NaN)`, 잘못된 5인자 `rgba(...)`

## 다음 권장 조치

1. 정적 검증기 변경은 유지한다.
2. 수족관·소리 가이드를 3~4개 핵심 규칙으로 줄이고, 그림판도 중복 요구를 정리한다.
3. 정의 누락과 명백히 잘못된 Canvas 색상 형식을 낮은 오탐 범위에서 추가 검출한다.
4. 전체 100건을 즉시 다시 돌리기 전에, 수족관 15건 + 소리 15건 + 꾸미기 10건의 40건 표적 시험을 한다.
5. 표적 시험에서 기존 수준 이상이면 그때 동일 100개 계획으로 최종 회귀 시험을 한다.

현재 판정은 **검증기 통과, 유형 가이드 보류, 후보 전체 배포 보류**다.
