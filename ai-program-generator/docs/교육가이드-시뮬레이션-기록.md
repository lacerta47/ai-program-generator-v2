# 멘토 가이드 B·C안 — 교실 시뮬레이션 기록 (5회 반복)

**설정(고정)** 한 학급 20명(1학년 6·2학년 7·3학년 7, 컴퓨터실, 1인 1기기, 프로젝터 1대) · **메인 교사 1명**(교사 계정 보유, 전체 진행) · **보조 교사 1명**(고등학생 멘토, 순회) · 45분 · 초안은 "멘토 1명당 4~6명 소그룹" 전제로 쓰였음.
**방법** 회차를 분 단위로 굴리며 "이 시점에 성인 두 명이 실제로 어디 있고 무엇을 하는가"를 적는다. 시간이 넘치거나, 아이가 방치되거나, 절차가 물리적으로 불가능하면 문제로 기록 → 교육안 수정 → 다음 회 재시뮬레이션.

## 1회 — 초안 그대로 (B안 1~6회차, C안 5·7회차)

### 걸린 문제 (16개)

| # | 어디서 | 무엇이 | 원인 |
|---|---|---|---|
| P1 | 모든 회차 몸놀이 | 20명이 한 명씩 명령(로봇 놀이) → 20×15초=5분 초과, 컴퓨터실 통로 좁아 두 걸음 이동 불가 | 소그룹 전제 |
| P2 | 1회차 로그인 | 1학년 6명 PIN 타이핑 불가, 성인 2명이 20대 순회 → **실측 12~15분**(계획 5분) | 인원비 |
| P3 | 골라서 만들기 | "멘토가 질문을 읽어 준다"를 20명에게 할 수 없음. 진도가 제각각 | 인원비 |
| P4 | 찾기(배지) | 아이마다 "①이 어디야?" 짚기를 성인이 확인 → 20×30초=10분 | 인원비 |

| P7 | 2·3·4회차 고치기 | 1학년 6명은 성인이 대신 쳐야 함 → 보조 1명이 6명 순회 = 6분, 그동안 나머지 14명 방치 | 타이핑 |
| P8 | 3회차 비교 | 1회차에 결석·실패한 아이(예상 3~4명)는 비교할 카드가 없음 | 결측 |
| P9 | 매 회차 | 빨리 끝난 아이(예상 5~6명)가 5분 이상 놀며 산만 | 속도 차 |
| P10 | 5회차 서술형 | 1학년 6명 받아쓰기 = 성인 2명이 6명 전담 → 나머지 14명 방치 | 타이핑 |
| P11 | 6회차 발표 | 20명 × 1분 + 전환 = **25분**(계획 12분) | 인원 |
| P12 | 전체 | 메인·보조 역할 구분이 문서에 없음 → 둘 다 같은 아이에게 감 | 역할 미정의 |
| P13 | 전체 | 주목 신호가 없어 "다 같이 보세요"가 안 먹힘 | 신호 부재 |
| P14 | 전체 | 시범을 "멘토 기기"로 하는데 20명이 볼 수 없음 → 프로젝터 필요, 절차에 없음 | 소그룹 전제 |
| P15 | 전체 | AI 생성 실패율 10~15% → 매 회차 2~3명 실패. 처리 주체·예비 작품 없음 | 실패 처리 |
| P16 | 운영 | 20명 × (생성 1 + 고치기 1~2) = 회차당 40~60회 생성. 교사 풀·학생 한도 설정 지침 없음 | 쿼터 |

### 수정 (교육안 v2 반영)
- **역할 정의**: 메인 = 프로젝터 시범·전체 신호·타임키퍼. 보조 = 순회·실패 기기·**느린 3명 전담**·명단 체크표.
- **주목 신호**: "로봇 정지!" → 손 머리(기기에서 손 뗌). 매 회차 첫머리에 연습 1회.
- **짝 체제**: **3학년+1학년 / 2학년+2학년** 고정 짝. 읽기·타이핑은 짝(3학년)이, 1학년은 "말하는 사람·확인하는 사람". 짝 배치는 교사가 미리.
- **몸놀이를 전체 놀이로**: 로봇 명령은 "반 전체가 로봇, 메인이 명령" → 순서 바꾸기 시연. 박수·반복·만약 카드는 원래 전체 놀이라 그대로. **자리에서 하는 버전**을 기본으로.
- **동기화 진행**: 골라서 만들기는 메인이 프로젝터로 같은 유형을 열고 **"질문 하나 골랐으면 손 머리"** 신호로 한 문항씩. 읽기는 짝.
- **확인 신호 = 짝 체크 + 표본**: 짝에게 말하기(전원) + 보조가 회차당 5명 듣고 **명단 체크표**에 표시. 6(8)회차 동안 전원 1회 이상.
- **로그인 선처리**: 보조가 수업 10분 전 20대 로그인(명단 PIN). 아이는 자기 이름 화면 찾기. 3학년만 2회차 열기 때 직접 로그인 1회 연습.
- **고치기 문장 칠판 제시**: 회차별 고치기 문장을 칠판에 써 두고 베끼기. 1학년은 짝이 침.
- **다 한 사람 카드**: 회차별 추가 고치기 미션 3개를 칠판 옆에. 빨리 끝난 아이용.
- **예비 작품**: 보조가 교육테스트 게시판의 예시 작품을 프로젝터로 열 수 있게 준비(결측 대체).
- **발표 → 갤러리 워크**: 절반은 자리에서 설명, 절반은 돌며 좋아요, 6분 후 교대.
- **쿼터 지침**: 학생 일일 한도 4, 교사 풀 ≥ 회차수 × 70 (B 420, C 560). 담당 교사가 발급 시 설정.
- **1회차 시간표 재배정**: 로그인 선처리로 5′ 회수, 서로 보기 8′→4′.

## 2회 — v2로 재시뮬레이션

### 굴려 본 결과
- 1회차 44분에 종료. 로그인 선처리가 결정적.
- 동기화 진행에서 **선택지 수가 짝마다 달라**(앞 답에 따라 다음 질문이 달라짐) "3번 질문"이 짝마다 다름 → 메인이 문항 내용을 읽을 수 없음. 신호만("골랐으면 손 머리") 주고 내용은 짝이 읽는 걸로 이미 설계했으나, **메인이 프로젝터에서 자기 화면을 읽어 주는 순간** 아이들이 그걸 따라 고름.

### 걸린 문제 (6개)

| # | 어디서 | 무엇이 |
|---|---|---|
| P17 | 동기화 진행 | 메인이 자기 화면 선택지를 읽으면 20명이 똑같이 고름(다양성 소멸) |
| P18 | 짝 체제 | 짝 결석 시 1학년 혼자 남음 (예상 회차당 1~2명) |
| P19 | 5회차 | 3학년이 자기 것 + 1학년 것 두 계획서를 침 → 3학년 과부하, 1학년 수동적 |
| P20 | 2회차 룰렛 | 20명 중 3명 생성 실패(룰렛은 오류 잦음) → 보조가 3명 재생성에 6분 |
| P21 | 6회차 QR | 교실에서 QR을 띄워도 **보호자가 없어 찍을 사람이 없음**. 5분이 낭비 |
| P22 | 갤러리 워크 | 돌아다니는 절반이 좋아요만 누르고 설명을 안 들음 |

### 수정
- **메인은 선택지를 읽지 않는다**: 프로젝터엔 질문 화면을 띄우되 "**여러분 화면의 질문을 짝이 읽어 줘요**"만. 메인이 고르는 건 🎲로(시범 다양성).
- **3인조 허용**: 결석 시 이웃 짝에 붙여 3인조. 역할은 말하는·적는·확인하는.
- **5회차 = 짝 계획서 하나**: 짝이 계획서 **한 장**을 함께(3학년이 치고 1학년이 말하고 확인). 1학년도 자기 것을 원하면 `더 키우기` + 이름칸만. → 1학년의 개인 서술형 작품은 목표에서 뺌(정직하게).
- **2회차 유형 교체**: `룰렛·뽑기` → **`칭찬·운세 뽑기`**(버튼 → 메시지, 입력·출력 가장 단순, 오류 적음). 룰렛은 대안으로.
- **QR 제거 → 알림장**: 교실에서는 `공유하기`를 열어 "이게 QR이야" 1분만. **반 게시판 주소 + 관람 PIN을 교사가 알림장으로 보호자에게**. 가이드에 교사용 알림장 문구 추가.
- **갤러리 워크에 '질문 카드'**: 돌아다니는 아이는 자리 아이에게 **"어디가 입력이야?"** 한 가지를 묻고 답을 들어야 좋아요를 누름.

## 3회 — v2.1 재시뮬레이션 (C안 5·7·8회차 집중)

### 굴려 본 결과
- C-5 고치기 탐정: "라운드당 7분 × 3, 성인이 두 칸 대필"은 20명에서 불가. 
- C-7 팀 작품: 20명 → 7팀(3·3·3·3·3·3·2), 기기 7대. 합의 8분 동안 성인 2명이 7팀 → 팀당 1분. 다툼 2팀 발생 시 나머지 5팀 방치.
- C-8 발표: 팀 7 × 1.5분 = 10.5분 + 개인 갤러리 12분 = 가능하나 도감·정리 시간이 4분밖에 안 남음.

### 걸린 문제 (5개)

| # | 어디서 | 무엇이 |
|---|---|---|
| P23 | C-5 | 3라운드 × 20명 대필 불가. 두 칸 개념은 짝으로 충분히 됨 |
| P24 | C-7 합의 | 성인 개입 없이 팀이 8분 안에 합의 못 함(예상 7팀 중 3팀) |
| P25 | C-7 기기 | 3인 1기기에서 적는 사람 외 2명이 생성 대기 30초 동안 놂 → 다툼 씨앗 |
| P26 | C-8 | 팀 발표 + 개인 갤러리 + 도감 + 수료를 45분에 다 넣으면 도감이 2분 |
| P27 | C-5 시범 | "멘토의 망가진 작품"을 보조 기기로 보여 줄 수 없음 → 프로젝터로 메인이 |

### 수정
- **C-5 = 짝 탐정 2라운드**: 라운드1 각자(짝이 대필) · 라운드2 짝이 문제 내기. 라운드3 삭제. 두 칸은 **칠판의 두 칸 틀**을 보며 짝이 친다.
- **C-7 합의 종이 + 3분 모래시계**: 합의 종이에 **칸이 세 개**(먼저 / 그다음 / 만약) 뿐이고 각 칸 옆에 이름 쓰는 칸. 규칙 "한 사람 한 칸" → 합의가 아니라 **배분**이 됨(다툴 여지 감소). 3분 지나면 가위바위보. 메인은 1분마다 "지금 몇 번째 칸?" 전체 신호. 보조는 다투는 팀만.
- **C-7 대기 역할**: 생성 대기 중 확인하는 사람은 "예측 카드"(우리 것 중 뭐가 제일 먼저 나올까 종이에 ○), 말하는 사람은 발표 첫 문장 연습.
- **C-8 분리**: 개인 갤러리는 **7회차 끝 8분**으로 앞당김(팀 작품 만든 뒤 남는 시간). 8회차는 팀 발표 + 도감 + 수료에 집중.
- **C-5 시범은 메인이 프로젝터로**, 보조는 그동안 느린 3명 기기에 예비 망가진 작품을 열어 둠.

## 4회 — v2.2 재시뮬레이션 (시간표·실패율·결측 정밀)

### 굴려 본 결과
- 전 회차 43~45분 안에 들어옴. 버퍼 2분은 실제로 항상 소진됨.
- 매 회차 AI 실패 2~3명은 보조가 처리 가능(재생성 1회 → 그래도 실패면 예비 작품). 단 **보조가 실패 처리 중이면 느린 3명 전담이 비어** 두 역할이 충돌.
- 3회차 "1회차 카드와 비교": 결측 아이는 예비 작품으로 대체 OK.
- 4회차 퀴즈: 20명이 문제를 다 맞혀 "틀리면"을 못 보는 아이 다수 → "일부러 틀리기"를 **전체 지시**로.

### 걸린 문제 (4개)

| # | 어디서 | 무엇이 |
|---|---|---|
| P28 | 보조 역할 | 실패 처리 vs 느린 3명 전담 충돌 |
| P29 | 4회차 | "틀리면"을 못 본 아이가 조건을 못 봄 |
| P30 | 2회차 | 3학년 직접 로그인 연습이 열기 3분을 넘김 |
| P31 | 전체 | 소리: 20대 중 몇 대가 켜져 있으면 수업 붕괴. 선처리 항목에 없음 |

### 수정
- **보조 우선순위**: ① 실패 기기(예비 작품으로 2분 내 종료) ② 느린 3명 ③ 명단 체크. 느린 3명은 **짝이 1차 도움**이라 보조는 2차.
- **4회차 전체 지시**: "다 같이 일부러 틀려 봅니다, 로봇 정지 후 3·2·1 틀리기!" 를 절차에 삽입.
- **3학년 로그인 연습 삭제**: 로그인은 전 회차 선처리. 궁금해하는 아이에겐 6(8)회차 뒤 남는 시간에.
- **선처리 체크리스트에 소리 끄기·화면 밝기·브라우저 탭 하나만** 추가.

## 5회 — v2.3 최종 재시뮬레이션

### 굴려 본 결과
- B안 6회차, C안 8회차 전부 45분 내. 성인 2명의 위치가 매 분 정의됨.
- 확인 신호: 짝 체크로 전원, 보조 표본 5명/회 → B안 6회 = 30명분(전원 1회 이상 + 10명 2회). C안 8회 = 40명분.
- 쿼터: 20명 × 회차당 최대 3회 = 60. 학생 일일 한도 4, 교사 풀 B 420 / C 560이면 여유.

### 남은 한계 (교육안으로 못 고치는 것 — 정직하게 기재)
| 항목 | 내용 | 대응 |
|---|---|---|
| L1 | 1학년의 **개인 서술형 작품**은 만들지 못한다(짝 작품). | 목표 표에서 뺐음. 1학년 목표는 "말로 계획하기" |
| L2 | 보조가 고등학생 1명이면 **실패 3명 + 느린 3명 + 체크표**를 한 회차에 다 못 한다. 2회차 이후 익숙해지면 가능. | 1회차만 보조 2명 권장(가능하면) |
| L3 | 팀 작품(C-7)은 툴에 팀 기능이 없어 **한 계정**에 만든다. 나머지 팀원의 도감엔 팀 작품이 안 남는다. | 8회차에 각자 `더 키우기`로 팀 작품을 자기 계정에 복사(선택, 시간 남으면) |
| L4 | 몸놀이를 자리에서 하면 1회차 '순서'의 **결과가 달라진다** 체감이 약하다. | 메인이 프로젝터 앞에서 직접 로봇 시연(두 명령 순서 바꿔 두 번) |
