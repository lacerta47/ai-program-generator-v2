# 골라서 만들기 퀴즈·룰렛 품질 개선

[작업 #192](https://github.com/lacerta47/ai-program-generator-v2/issues/192) · 기준 SHA `bdfaad693746e7d30c5cb25738330462d1ab22eb`

- 퀴즈는 시간 제한을 명시한 경우에만 경고 설정을 쓰고, 숫자 주제를 떠나면 이전 연산과 숫자 범위가 프롬프트와 미리보기 계획에서 빠진다. 그림 보기 옵션은 고른 주제를 유지한다.
- 퀴즈 학습 피드백은 채점 결과와 함께 정답·쉬운 이유 한 문장을 보여준다. 아동이 설명을 읽은 뒤 직접 다음 문제로 넘어간다. 빈 답 안내, Enter와 한글 조합 입력, 시간 종료와 채점의 중복 처리 방지, 마지막 문제·목숨 소진 뒤 결과와 다시하기를 지침에 담았다. 뺄셈은 음수 답을 제외하고 곱셈은 두 수를 한 자리로 제한한다.
- 룰렛에서 직접 명단 또는 인원 수를 입력하면 현재 목록을 원판에 반영한다. 고정 칸 선택은 해당 모드에서 숨기고, 이전 용도의 이름·축하 설정은 조립하지 않는다. 회전 중 무음과 멈춤 효과음은 따로 고를 수 있다. 당첨 결과는 항상 표시하며, 축하 효과는 결과를 가리지 않는다.
- 룰렛 검사는 두 회전에서 화면의 실제 번호 위치와 범례, 당첨 문구를 비교한다. 회전 중 중복 입력, 같은 당첨 항목 반복, 다음 회전에서의 직전 당첨 항목 제외, 동작 줄이기 설정을 점검한다. 번호 범례는 원판의 이름을 수평으로 읽을 수 있게 하고 포인터의 위치와 결과가 어떻게 이어지는지 보여준다.

## 검증

- `npm test` 단위 242건 통과, 기존 선택 실행 2건 제외. `npm run test:api` 67건 통과. 린트, 타입 검사, CI와 같은 공개 더미 설정의 프로덕션 빌드 통과.
- `node --test scripts/quality-action-checks.test.mjs`는 로컬 격리 미리보기에서 검사용 정상 예시 6개와 오류 예시 2개를 실행한다. 보기 퀴즈와 직접 입력 퀴즈, 시간 종료, 룰렛 같은 결과 반복·제외·원판 재조작과 AI 위임을 통과했다. 동작하지 않는 확인 버튼과 포인터에 맞지 않는 결과는 각각 실패로 검출했다.
- 생성물은 `node scripts/inspect-quality-actions.mjs <결과폴더> quiz,roulette`로 검사한다. 이전 계약의 저장 결과는 추가 DOM 표식이 없을 수 있으므로 검사 불일치를 실제 사용 버그와 구분한다. 최초 로컬 구현 단계에는 유료 생성이 없었으며, 이어서 사용자 승인으로 [실제 10건을 검증](quiz-roulette-live-validation-20261122.md)했다.
