- 날짜: 2026-11-19 KST
- 상태: 채택 (브리지 변경 초안, main 미병합)
- 범위: CLI 협업 검토의 요청 설정·증거 기록·공통 지침
- 결정 주체·근거: 사용자의 모델/추론 수준 명시·실제 응답 모델/검토 SHA 기록·양쪽 지침 정렬 요청, [Issue #182](https://github.com/lacerta47/ai-program-generator-v2/issues/182), [Claude 협의](../ai-bridge/inbox/claude/2026-11-19-model-policy-review.md), [재검토](../ai-bridge/inbox/claude/2026-11-19-model-policy-recheck.md)

- 대체된 후속 결정: 없음

## 결정

요청 기본값은 config.json의 Codex `gpt-6.1-sol`/`medium`, Claude `claude-fable-5-2`/`medium`이다. Claude도 이에 동의했다. 검토 성격에 따라 추론 수준을 변경하려면 명시적인 설정 변경과 기록으로 남기며 자동으로 모델을 바꾸지 않는다.

요청 모델과 실제 응답 모델은 별도로 기록한다. Claude의 실제 assistant 모델 필드를 수집하고, Codex CLI가 제공하지 않는 모델과 양쪽의 실제 적용 effort는 미확인으로 둔다. AI 자기보고·초기 선택 모델·구독 등급으로 응답 증거를 꾸며내지 않는다. 정확한 ID가 다르면 날짜 접미사도 임의 동등화하지 않고 알린다.

검토 커밋과 호출 HEAD는 일치해야 하며 편지 외 변경은 호출 전에 커밋한다. 호출 측이 Git으로 확인한 SHA/HEAD와 AI가 보고한 값은 구분한다. 실패도 정상 답신과 별도로 기록한다.

프로젝트 규칙은 활성 프로젝트 AGENTS.md 한 곳으로 통합하고 루트 Claude/Codex 진입 파일이 이를 가리킨다. 브리지는 같은 원본 내용을 명시 전달하고 SHA-256을 기록한다. 사용자 커스터마이징을 제한하되 서비스별 시스템/관리자 정책이 완전히 같다는 주장은 하지 않는다.

## 이유와 대안

가변 기본값은 다른 대화창에서 선택한 모델과 달라질 수 있다. 명시한 요청과 관측한 응답을 구분해야 결과를 재현하고 비교할 수 있다. 다른 모델로 조용히 하향하거나 세션을 재사용하는 대안은 채택하지 않았다. CLI가 모델 증거를 주지 않을 때 별도 API 인증이나 프록시를 만들지 않고 그 한계를 그대로 기록한다.

## 검증과 미확인 사항

[실제 호출 검증 기록](../ai-bridge/model-settings-validation-20261119.md)에 CLI 버전·SHA·공통 지침 해시·소요를 남겼다. 이는 브리지 프로토콜의 검증이며 제품 생성·운영 기능 검증이나 main 병합 승인이 아니다.
