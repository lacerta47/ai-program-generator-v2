# 생성 100건 가이드 축약 재시험 (2026-09-10)

## 결론

유형 가이드를 축약한 후보는 직전 후보 대비 엄격 성공률이 74/100에서 82/100으로 8%p 회복했다. 생성 실패도 7건에서 2건으로 줄고 평균 생성 시간은 74초에서 67초로 줄었다.

다만 동일 계획 짝비교에서 직전 후보만 성공한 경우가 16건, 새 후보만 성공한 경우가 24건이며 정확 이항검정 양측 p값은 0.2682다. 개선 방향은 긍정적이지만 이번 100건만으로 통계적으로 확정된 개선이라고 단정할 수 없다. 최초 개선판의 86/100에도 아직 4%p 못 미친다.

현재 판정은 **축약 가이드 유지 후보, 즉시 배포 확정은 보류**다.

## 적용한 변경

- 그림판 가이드: 9개 규칙에서 직접 실패를 막는 5개 규칙으로 축약
- 소리 가이드: 7개 규칙에서 사용자 입력·일회용 노드·단순 연결·유한한 시간의 4개 규칙으로 축약
- 수족관 가이드: 소리 공통 규칙과의 합산을 없애고, 핵심 기능 우선·유효한 Canvas 색상·소리 실패 격리·SVG 버튼의 4개 독립 규칙으로 축약
- 정적 검증기 변경은 그대로 유지
- 재시험 스크립트에 비교 기준 폴더 선택 옵션 추가

## 시험 범위

- 동일 계획 신규 생성: 100건
- 비교 기준: 직전 재시험 후보 100건
- 생성 결과: 98건
- 생성 실패: 2건
- 브라우저 기본·확장 검사: 신규 98건 전부 완료
- 전체 산출물: 결과 행 200개, 동작 기록 191개, 스크린샷 191개
- 엄격 성공 기준: 생성 성공 + 해당 버전 정적 게이트 통과 + 기본/확장 브라우저 검사 무오류

## 축약 대상별 평가

### 수족관: 성공

15건 모두 생성됐고 13건이 엄격 성공했다. 남은 2건은 문법 오류 1건과 `drawAquarium` 정의 누락 1건이며 둘 다 정적 게이트가 차단했다. 이전에 발생한 NaN 색상, 잘못된 rgba, `Coral` 정의 누락은 재발하지 않았다.

### 소리: 추가 개선 필요

성공률은 12/15로 유지됐다. 이전의 문법 오류 3건은 사라졌지만 다음 런타임 오류 3건으로 바뀌었다.

- AudioContext 또는 gain 준비 전 `currentTime`·`gain` 접근
- 페이지 로드 중 null gain 접근
- 연결하지 않은 AudioNode 목적지 `disconnect`

짧은 규칙만으로 응답 완결성은 좋아졌지만 오디오 초기화 계약을 충분히 강제하지 못했다.

### 그림판: 실행 환경 계약 정리가 우선

15건 중 2건은 모델 응답 정리 실패, 2건은 Clipboard API 권한 오류, 1건은 정적 게이트 오탐으로 엄격 성공이 10건이었다.

격리 미리보기는 보안상 Clipboard 기능을 허용하지 않는다. 그러나 일부 설문 계획은 클립보드 복사를 명시적으로 요구한다. 현재는 모델이 요구를 충실히 따르면 실행 검사에서 실패하는 구조다. 가이드를 더 조정하기 전에 다음 중 하나로 제품 계약을 통일해야 한다.

- 설문에서 클립보드 복사를 제거하고 PNG 다운로드로 대체
- 서버에서 해당 선택을 PNG 다운로드 안내로 변환
- 보안 경계를 바꾸지 않고 미리보기에서 기능 제한을 명확히 안내

보안 invariant를 고려하면 PNG 다운로드로 대체하는 방향이 가장 안전하다.

## 남은 실패와 검증기 상태

축약 후보의 브라우저 오류 15건 중 게이트가 차단한 것은 3건이고 12건은 미탐했다. 게이트 차단 4건 중 1건은 브라우저 정상으로 오탐이었다.

주요 미탐 형태:

- 없는 DOM 요소의 `addEventListener`·`offsetWidth` 접근
- AudioContext/gain 초기화 전 속성 접근
- 시작하지 않은 AudioScheduledSourceNode 정지
- 연결되지 않은 AudioNode 목적지 해제
- Clipboard 권한 정책 위반
- 이미 제거된 노드를 `replaceChild` 대상으로 재사용

미탐을 한 번에 모두 정규식으로 막으면 오탐이 커질 수 있다. 반복 사례가 명확한 DOM 리터럴 조회와 오디오 초기화 패턴부터 제한적으로 추가하는 것이 적절하다.

## 다음 권장 조치

1. 수족관 축약 가이드는 유지한다.
2. 소리 가이드는 길이를 늘리지 않고 `ensureAudio()` 성공 뒤에만 모든 오디오 속성을 읽는 한 가지 계약으로 더 명확히 만든다.
3. 그림판의 클립보드 선택을 PNG 다운로드로 정규화해 보안 미리보기와 요구사항 충돌을 제거한다.
4. 줄바꿈 없는 주석 게이트의 이번 오탐 1건을 분석해 탐지 범위를 정밀화한다.
5. 위 세 변경 후 전체 100건보다 먼저 소리 15건 + 그림판 15건의 30건 표적 시험을 수행한다.
