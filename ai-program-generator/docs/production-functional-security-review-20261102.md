## 결론

자동 기능·권한 검사 333건과 운영 HTTP·보안 경계 검사 129건은 모두 통과했다. 운영 의존성 감사는 취약점 0건이다. 개발 도구를 포함하면 중간 위험으로 분류되는 패키지 항목 26건이 있으며, 근본 권고 3개가 여러 경로에 전파된 결과다.

2026-11-03 시점에 전체 기능의 운영 완료 판정을 보류했다. 실제 신규 생성은 완료되고 ZIP 다운로드도 됐지만 Chrome의 결과 미리보기가 빈 화면으로 관찰됐다. 서버의 미리보기 응답은 200이며 HTML·스타일·스크립트가 존재하고 CSP 격리 헤더도 확인됐다. 화면 렌더링 문제의 원인은 아직 확정하지 못했다. 이후 브라우저 제어 도구가 현재 URL을 안전하게 확인할 수 없다는 이유로 화면 조작을 중단시켜, 수정 생성 및 관리자 세부 화면 검사를 계속하지 않았다.

## 승인 및 운영 영향

- 사용자 선택에 따라 운영에서는 기존 관리자 세션만 사용했고, 선생님·학생 권한은 자동 검사로 확인했다.
- 유료 호출은 최대 2회 승인받았다. 실제 실행은 신규 생성 1회이며 수정 생성은 실행하지 않았다.
- 첫 생성은 직접 만들기 화면에서 기존에 저장된 블록 쌓기 초안이 복원된 내용으로 진행됐다. 입력이 안정되기 전 빈 입력 검사로 판단해 버튼을 눌렀으므로, 이 동작을 필수 입력 차단 통과 근거로 삼지 않았다.
- 기존 작품·계정·한도·관리자 설정은 변경하지 않았다. 새 결과물을 게시판에 게시하지 않았다. 생성·미리보기 저장·사용량 집계와 통상적인 페이지 방문 집계는 발생할 수 있다.
- 소스 수정·커밋·푸시·추가 배포는 하지 않았다. 이 문서와 output의 검사 자료는 로컬 기록이다.

## 관리자 실제 화면 및 유료 생성

- Chrome 관리자 로그인, 마이페이지 별명·사용량·개념 도감·기존 작품 목록을 확인했다.
- 직접 만들기 입력 폼, 기존 초안 복원, 생성 진행 및 완료, 교육 메타 표시를 확인했다.
- 첫 생성 결과의 교차 출처 iframe은 `https://ai-program-generator-v2-preview.vercel.app`이며 `sandbox="allow-scripts"`이다. reCAPTCHA iframe과 생성물 iframe을 구별해 확인했다.
- 생성 미리보기 서버 응답은 200, HTML 13,815자, canvas 및 script가 존재했다. 메인 앱 CSP의 frame-src와 미리보기 CSP의 frame-ancestors도 서로 허용한다. 정상 헤더 확인만으로 실제 렌더링 성공이라고 판정하지 않았다.
- 로컬 다운로드 폴더에 ZIP이 생성됐고 index.html·style.css·script.js 3개 파일과 비어 있지 않은 내용이 확인됐다. 게임 조작·수정 생성까지 완료한 결과는 아니다.
- 브라우저 콘솔 검사에서는 오류가 포착되지 않았으나, 전체 iframe 오류를 수집했다고 보장할 수 없다.

## 남은 확인 및 우선순위

1. 우선 확인: 실제 Chrome에서 빈 미리보기가 재현되는지 확인하고, 브라우저 차단·프레임 로딩·앱 렌더링 중 원인을 구분한다. 생성 API 성공과 별개로 사용자 핵심 경로라 확인이 필요하다.
2. 운영 수정 생성 1회: 당시 수정 생성은 실행하지 않았다. 후속 유료 생성 검증에는 새 승인이 필요하다.
3. 관리자 각 상세 화면의 검색·정렬·페이지 이동, 설정 저장은 전체 운영 검사 완료로 표기하지 않는다. 설정 저장 및 게시·삭제는 이번 운영 검사에서 실행하지 않았다.
4. 선생님·학생의 실제 브라우저 업무 및 일반 회원 가입·메일 인증은 사용자 선택에 따라 이번 범위에서 제외했다. 역할별 자동 검사만 통과했다.
5. 개발 도구 Moderate 전파 경로는 별도 호환성 검증을 거쳐 보완한다. 운영 부하·PIN 대입·실제 30명 유료 생성은 실행하지 않았다.

현재 자료는 제한된 회귀·보안 경계 점검 결과이며, 전체 기능 또는 침투 테스트의 무결점 인증이 아니다.

## 2026-11-03 인증서 문의 후속

일부 클라이언트 환경에서 NET::ERR_CERT_AUTHORITY_INVALID 계열 경고가 간헐적으로 발생했다는 제보가 있었다. 당시 주소와 인증서 발급자는 확인되지 않았다. 2026-11-03 조회에서는 운영 도메인(Let's Encrypt, 2027-01-06 만료)과 미리보기 도메인(Google Trust Services, 2027-01-29 만료)의 TLS 인증서 검증·HTTPS 응답이 당시 모두 정상이었다. HTTP 운영 주소도 HTTPS로 308 이동했다.

과거 오류의 원인은 확정하지 못했다. 사용자는 재발 시 확인할 항목으로 남기고 넘어가기로 했다. 따라서 '해결 완료'나 '모든 일반 환경에서 발생하지 않음'으로 표기하지 않는다. 인증서 설정 변경·재발급·경고 우회는 진행하지 않았다. 이 문의와 앞선 빈 미리보기 현상 사이의 인과관계도 확인되지 않았다.
