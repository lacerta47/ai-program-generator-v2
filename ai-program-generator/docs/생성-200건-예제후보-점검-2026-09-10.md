# 생성 200건 예제 후보 점검 (2026-09-10)

## 결론

동일한 무작위 계획 100개를 승인 예시 OFF/ON으로 각각 생성해 총 200회를 검사했다. 198건이 정상 생성됐고, 정적 게이트·기본 브라우저 검사·확장 조작 검사·과복제 검사를 모두 통과한 158건을 `교육테스트` 카테고리에 예제 후보로 업로드했다.

- 전체 기술 통과: 158/200 (79%)
- 예시 OFF: 77/100
- 예시 ON: 81/100
- 짝비교: 양쪽 통과 60, OFF만 17, ON만 21, 양쪽 실패 2, 정확 양측 p=0.6271
- 코드 과복제 고위험: 0건
- 서버 업로드 재검증: 158/158 존재 확인

ON의 성공률이 4%p 높았지만 통계적으로 유의하지 않다. 실제 승인 예시가 존재하는 7개 유형만 합치면 OFF 44/55, ON 43/55로 차이가 없었다. 현재 예시는 모두 `plan-only`라 이번 결과는 계획서 참고 효과만 측정하며, 완전한 코드 예시 효과를 증명하지 않는다.

## 4번 조치: 기능 누락·과복제 검사

- 계획 생성 시 선택 옵션별 요구사항을 구조화해 manifest에 동결한다.
- 생성 결과의 HTML/CSS/JavaScript와 실제 렌더 텍스트에서 선택 기능의 증거를 탐색한다.
- `넣지 마`, `없이`, `없어도` 같은 부정 선택과 충돌할 가능성이 있는 표현을 별도 표시한다.
- 완전한 코드 예시가 사용되면 정규화 코드 조각 포함률을 계산하고, 35% 이상이면 과복제 고위험으로 분류한다.
- 예시 제목이 새 결과에 새어 들어간 경우도 과복제 고위험으로 분류한다.

기능 증거 검사는 휴리스틱이므로 자동 탈락 기준이 아니라 수동 검토 우선순위다. 기술 통과 후보 158건 중 129건은 적어도 한 선택 기능을 화면·코드 문자열만으로 확정하지 못했고, 27건은 부정 선택 충돌 가능성이 표시됐다. 실제 동작을 의미적으로 확인하기 전에는 최종 예시로 확정하지 않는다.
