# LUN 수업 가이드 · B안 — 6회차 "몸으로 먼저, 화면으로 확인" (v2.3)

**누가 읽나** 처음 가르치는 사람. 메인 교사(전체 진행)와 보조 교사(고등학생 멘토 가능) **두 명**이 이 문서 하나로 같은 수업을 합니다.
**누구에게** 초등 1~3학년 **한 학급 20명**(학년 섞임). 컴퓨터실, 1인 1기기, 프로젝터 1대.
**얼마나** 45분 × 6회. 회차마다 새 개념은 **하나**만.
**도구** LUN(eduai-lun.co.kr). 학생 계정(학교·학번·PIN)은 담당 교사가 미리 발급.

> 이 문서는 20명 교실을 분 단위로 5회 시뮬레이션해 고친 판입니다(`교육가이드-시뮬레이션-기록.md`). "성인 두 명이 이 순간 어디 있고 무엇을 하는가"가 매 단계에 적혀 있습니다.

---

## 0. 이 가이드의 노선

```
   몸으로 먼저 (전체 놀이 5분)  →  화면에서 확인 (짝과 만들기)  →  내 작품에서 찾기 (배지)
```

- **1~2학년은 몸이 화면보다 빠릅니다.** 개념을 설명하지 않고 놀이로 겪게 한 뒤 화면에서 "아까 그거네"를 만듭니다.
- **놀이는 20명이 한꺼번에**, 자리에서 합니다. 컴퓨터실 통로는 좁습니다.
- 개념은 앱 배지 다섯 글자만: **`순서` `입력` `출력` `반복` `조건`.** 알고리즘·변수·함수·코딩은 어른도 쓰지 않습니다.

## 1. 교실 운영 체제 — 20명을 두 명이 굴리는 법

### 역할
| | 메인 교사 | 보조 교사 |
|---|---|---|
| 위치 | 프로젝터 앞 | 교실 뒤에서 순회 |
| 하는 일 | 시범(프로젝터), 전체 신호, **시간 지키기**, 몸놀이 진행 | **① 실패 기기 처리 → ② 느린 3명 → ③ 명단 체크표** (이 순서) |
| 안 하는 일 | 개별 기기 붙잡기 | 전체를 향해 말하기 |

### 짝 체제 (가장 중요)
- **3학년+1학년, 2학년+2학년** 고정 짝. 담당 교사가 1회차 전에 짝표를 만들어 자리에 붙입니다.
- 짝 안의 역할: **읽는·적는 사람**(3학년/2학년 중 한 명) · **말하는·확인하는 사람**(1학년/다른 2학년). 회차마다 2학년 짝은 역할을 바꿉니다. 1학년은 6회 내내 말하는 사람이어도 됩니다.
- 결석하면 이웃 짝에 붙여 **3인조**.
- 이 체제 덕에 "읽어 주기·타이핑·1차 확인"이 짝 안에서 끝나고, 성인은 2차만 합니다.

### 신호
- **주목**: 메인이 "**로봇 정지!**" → 아이들 손을 머리에(기기에서 손 뗌). 매 회차 첫머리에 1번 연습.
- **진행**: "골랐으면 손 머리" → 80%가 손 머리면 다음. 나머지는 짝·보조가 마무리.
- **다 한 사람**: 칠판 옆 **"다 한 사람 카드"**(회차별 고치기 미션 3개). 빨리 끝나면 그걸 합니다. 돌아다니지 않습니다.

### 확인 신호는 이렇게 받습니다
- **전원**: 짝에게 말하기(짝이 듣고 고개 끄덕).
- **표본**: 보조가 회차당 **5명**을 골라 듣고 **명단 체크표**(부록 E)에 ○. 6회 동안 전원 1회 이상.
- 못한 아이는 다음 회차 열기 3분에 메인이 전체 앞에서 "지난주 이름?"으로 한 번 더.

### 수업 전 선처리 (보조, 10분 전) — 부록 F 체크리스트
20대 로그인(명단 PIN) · **소리 끄기** · 브라우저 탭 하나만 · 화면 밝기 · 예비 작품 열 준비 · 칠판에 오늘 고치기 문장 + 다 한 사람 카드.
**아이는 로그인을 하지 않습니다.** 자리에 앉아 화면 위 자기 이름을 확인할 뿐입니다. (로그인 자체를 배우는 건 이 과정 목표가 아닙니다.)

### 쿼터 (담당 교사가 학생 발급 시)
학생 **일일 한도 4**, 교사 풀 **420 이상**(20명 × 회차당 최대 3회 × 6회 + 여유). 부족하면 3회차쯤 "만들기가 안 돼요"가 터집니다.

## 2. 사전 훈련 (메인·보조 함께 60분, 수업 전날까지)

| 순서 | 할 일 | 확인 |
|---|---|---|
| 1 | 학생 계정으로 로그인 (`로그인` → `학생` → `학교를 골라요` → 학번 `10101` 형식 → PIN → `학생 로그인`) | 오른쪽 위 이름 |
| 2 | `골라서 만들기`로 `소개·인사 카드` 완성 | `완성!` + 🧩 카드 |
| 3 | 고치기 1회 (`이렇게 되면 좋겠어요`만) | `무엇이 바뀌었을까요?` |
| 4 | `자랑하기`로 우리 반 게시판 올리기 → `게시판`에서 열기 | 게시 확인 |
| 5 | `만들기` 화면 4칸 읽기, 이름+동작①만으로 만들어 보기 | 최소 계획서로도 됨 |
| 6 | 마이페이지 `개념 도감` 5개 설명 읽기 | 배지 뜻 |
| 7 | **프로젝터 연결 + 화면 공유** 리허설, "로봇 정지" 연습 | 20명 관점 |
| 8 | 교육테스트 게시판에서 **예비 작품** 5개 골라 두기(카드·뽑기·시계·수족관·퀴즈) | 실패 대체용 |
| 9 | 일부러 실패: 계획서에 "아무거나"만 쓰고 만들기 → 고치기 | 실패 감각 |

**역할극 3개** (메인↔보조 번갈아)
- "안 돼요!"(화면 멈춤) → 보조: "잠깐, 내가 볼게" → 1분 안에 안 되면 **예비 작품**으로.
- "이상해요!" → "오, 고칠 거리다! 뭐가 이상해? 그걸 칠판 문장처럼 적어 보자."
- "몰라요" → "🎲 눌러 볼까?" / "짝은 뭐 골랐어?"

## 3. 툴 지도 — 어디를 누르나

| 화면 | 가는 길 | 이 가이드에서 쓰는 것 |
|---|---|---|
| **골라서 만들기** | 위 메뉴 `골라서 만들기` | `무엇을 만들까?` 타일 → `하나씩 골라요` → 🎲 `(AI가 골라줘)` → 이름 칸 → `다음` |
| **완성 화면** | 자동 | `○○ 완성!` · 미리보기 · 🧩 `이 프로그램은 이렇게 움직여요` ①②③ · 배지 5 · `새로 만들기` `더 키우기` `자랑하기` |
| **고치기 칸** | 완성 화면 아래 | `이렇게 되면 좋겠어요 (바라는 모습)` 필수 · `지금은 이래요 (지금 모습, 선택)` |
| **만들기(서술형)** | 위 메뉴 `만들기` | `프로그램 이름` · `어떻게 생겼나요?` · `어떻게 사용하나요?` · 동작 `① 먼저` `② 그다음` `③ 만약 ~하면요` · 결과의 `수정 저장` `게시판에 올리기` |
| **게시판** | 위 메뉴 `게시판` | 게시판 칩(우리 반) · 목록 · 미리보기 · 좋아요 · `공유하기` · `계획서 보기` |
| **마이페이지** | 오른쪽 위 이름 | `내 작품` · `개념 도감` · `별명 바꾸기` |
| **교사 콘솔** (메인만) | 오른쪽 위 → 교사 | `우리 반` · `우리 반 학습 현황` · `관람 PIN` |

안 쓰는 것: `신고`, 게시판의 `고치기`(남의 작품 가져오기). 물으면 "그건 선생님이 하는 거야."

## 4. 회차 한눈에

| 회차 | 새 개념 | 전체 몸놀이 | 화면 활동 | 산출물 | 확인 신호(짝에게) |
|---|---|---|---|---|---|
| 1 | **순서** | 반 전체가 로봇 | 소개·인사 카드 | 작품 1 | "먼저 ○○, 그다음 ○○" |
| 2 | **입력·출력** | 박수 치면 앉기 | 칭찬·운세 뽑기 + 고치기 1 | 작품 2 | "누르면(입력) 나와요(출력)" |
| 3 | **반복** | 열 번 대신 한마디 | 시계·타이머 / 수족관 | 작품 3 | "혼자 계속 움직여요, 반복" |
| 4 | **조건** | 만약 카드 놀이 | 퀴즈 (전체 '일부러 틀리기') | 작품 4 · 도감 5 | "만약 맞으면 ○○, 틀리면 △△" |
| 5 | (5개 합치기) | 내 계획 말로 하기 | `더 키우기` → 짝 계획서 4칸 | 짝 서술형 작품 1 | "우리가 쓴 대로 됐어요" |
| 6 | (자랑) | 세 문장 연습 | 게시 · 갤러리 워크 · 도감 | 게시 2 | 도감 5칸 짚으며 이름 |

**45분의 리듬** (성인 위치 포함)

```
 열기 3′(메인 전체)  │ 몸놀이 6′(메인 진행·보조 뒤에서 함께)  │ 화면 만들기 14′(메인 프로젝터 신호·보조 순회)
 찾기 8′(짝 활동·보조 표본 5명)  │ 서로 보기 6′  │ 정리·신호 4′(메인)  │ 버퍼 4′
```

늦어지면 "서로 보기" → "몸놀이 3′" 순으로 줄입니다. 만들기·찾기·확인 신호는 줄이지 않습니다.

# 회차별 가이드

틀: **한눈에 → 선처리 추가분 → 진행표(성인 위치) → 단계별(절차·멘트·툴) → 다 한 사람 카드 → 하지 말 것 → 막힐 때 → 확인 신호.** 굵은 멘트는 그대로.

---

## 1회차 — 순서: 로봇은 시키는 차례대로

**한눈에** `순서` · `골라서 만들기 → 소개·인사 카드` · 카드 1개

### 선처리 추가분
- 짝표 자리 부착 · 프로젝터에 `골라서 만들기` 화면 · 칠판: "다 한 사람 카드 ①배경 색 바꿔 줘 ②글자 크게 해 줘 ③내 이름 넣어 줘"

### 진행표
| 분 | 단계 | 메인 | 보조 |
|---|---|---|---|
| 0~3 | 열기 + "로봇 정지" 연습 | 전체 | 뒤에서 손 머리 시범 |
| 3~9 | 몸놀이 — 반 전체가 로봇 | 진행 | 함께 참여 |
| 9~23 | 카드 만들기 (동기화) | 프로젝터 신호 | 순회·실패 처리 |
| 23~31 | 찾기 — 짝에게 ① 짚기 | 프로젝터로 🧩 시범 | 표본 5명 듣기 |
| 31~37 | 서로 보기 | 시간 | 순회 |
| 37~41 | 정리·신호 | 전체 | 체크표 |
| 41~45 | 버퍼 | | |

### 단계별

**① 열기 (3′) — 메인**
- 멘트: "오늘은 **컴퓨터한테 순서대로 시키는 걸** 해요. 먼저 신호 하나. 내가 '**로봇 정지!**' 하면 손을 머리에! 해 볼까요? 로봇 정지!" (2회 연습)
- "옆에 있는 친구가 오늘 **짝**이에요. 짝이 화면 글을 읽어 주고, 못 치면 대신 쳐 줘요."

**② 몸놀이 — 반 전체가 로봇 (6′) — 메인, 자리에서**
- 절차: "여러분 전부 로봇이에요. 내가 시키는 **차례대로만** 해요." 명령 3개: **"손 들기 → 박수 한 번 → 앉기(자리에서 엉덩이 붙이기)"**. 한 번 한다. 그다음 **순서를 바꿔** 다시: "앉기 → 박수 → 손 들기." **"똑같은 세 개인데 순서가 바뀌니 다르지요?"**
- 그다음 아이 셋을 앞에 세워 명령 하나씩 말하게 하고(나머지는 로봇), 손가락으로 1·2·3.
- 멘트: **"로봇은 시키는 차례대로만 움직여요. 이걸 '순서'라고 해요."**
- 보조: 뒤에서 같이 로봇. 안 하는 아이 옆에 서서 같이 함(말 안 걸기).

**③ 카드 만들기 — 동기화 (14′)**
- 툴: `골라서 만들기` → **`소개·인사 카드`** 타일 → 질문 → 이름 → `다음`.
- 메인(프로젝터): 타일을 누르는 것까지만 같이. **"여러분 화면에 질문이 나와요. 질문은 짝이 읽어 줘요. 하나 골랐으면 손 머리!"** 80% 손 머리면 "다음!". 메인은 **선택지를 읽지 않습니다**(읽으면 20명이 똑같이 고릅니다). 메인 화면은 🎲로 진행해 시범만.
- 짝: 읽는 사람이 질문·선택지를 읽고, 말하는 사람이 고른다(손가락으로 짚으면 읽는 사람이 눌러도 됨).
- 이름 칸: 말하는 사람 이름. 못 치면 짝이.
- 기다리는 30초: 메인 **"지금 컴퓨터가 여러분이 고른 차례대로 만들고 있어요."**
- 보조: 실패(1분 넘음·빈 화면) 기기는 `새로 만들기` 1회 → 또 실패면 **예비 작품**(교육테스트 게시판 카드)을 그 기기에 열어 줌. "이건 준비해 둔 카드야, 오늘은 이걸로."

**④ 찾기 — 🧩와 배지 (8′)**
- 메인(프로젝터, 자기 카드로): 🧩 `이 프로그램은 이렇게 움직여요` ①②③을 짚으며 읽는다. **"아까 로봇 놀이랑 똑같아요. ① 먼저 이거, ② 그다음 이거. 이제 짝에게 자기 화면에서 ①이 어디인지 눌러서 보여 주세요."**
- 짝: 말하는 사람이 ①을 짚고 읽는 사람이 "맞아" 하면 끝. 역할 바꿔 한 번 더.
- 배지: 메인 **"이 글자 보이죠? '순서'. 우리가 몸으로 한 거랑 같은 이름."**
- 보조: 표본 5명에게 "①이 어디야?" → 짚으면 체크표 ○.

**⑤ 서로 보기 (6′)** — 짝끼리 다른 짝 화면 하나 보고 "너는 뭘 골랐어?" 한 가지. 메인: **"같은 카드인데 다 달라요. 고른 게 다르면 순서 속 내용이 달라져요."**

**⑥ 정리·신호 (4′) — 메인**
- "오늘 이름 하나?" → "순서!" → **"짝에게 말해 보세요: '먼저 ○○, 그다음 ○○.'"** (전원 동시에 30초)
- **확인 신호: "먼저 ○○, 그다음 ○○"** 자기 카드로.
- "다음 시간엔 컴퓨터한테 **말 거는 법**."

### 다 한 사람 카드
①배경 색 바꿔 줘 ②글자 크게 해 줘 ③내 이름 넣어 줘 — 고치기 칸 `이렇게 되면 좋겠어요`에 하나씩.

### 하지 말 것
- 몸놀이 전에 "순서" 설명 · 메인이 선택지 읽기 · 12개 타일 다 보여 주기 · 어른이 대신 누르기

## 2회차 — 입력·출력: 내가 시키면 컴퓨터가 대답해

**한눈에** `입력` `출력` · `칭찬·운세 뽑기`(대안 `룰렛·뽑기`) + 고치기 1회 · 작품 1개
(룰렛은 생성 오류가 잦아 20명 교실에선 뽑기가 기본입니다.)

### 선처리 추가분
- 칠판: 고치기 문장 **"버튼을 크고 노란색으로 해 줘"** · 다 한 사람 카드 ①"메시지를 세 개 더 넣어 줘" ②"버튼 이름을 '눌러 봐'로" ③"배경을 밤하늘로"

### 진행표
| 분 | 단계 | 메인 | 보조 |
|---|---|---|---|
| 0~3 | 열기 — "지난주 이름?" | 전체 | 결석·짝 재배치 |

| 9~21 | 뽑기 만들기 (동기화) | 신호 | 순회·실패 |

| 37~41 | 정리·신호 | 전체 | 체크표 |

- **만들기 (동기화)**: `골라서 만들기` → **`칭찬·운세 뽑기`** → 질문(`어떤 메시지를 뽑을까?` …) 짝이 읽기 → "골랐으면 손 머리" → 이름 → `다음`. 완성: **"버튼 눌러 봐요. 누르는 게 뭐? 입력! 나온 글자는? 출력!"**

## 3회차 — 반복: 열 번 시키지 말고 "반복!"

### 진행표
| 분 | 단계 | 메인 | 보조 |
|---|---|---|---|
| 0~3 | 열기 — "버튼 누르면? 나온다!" | 전체 | 재배치 |
| 3~9 | 몸놀이 — 열 번 대신 한마디 | 진행 | 참여 |
| 9~23 | 시계 만들기 (동기화) | 신호 | 순회·실패 |
| 23~31 | 찾기 — 혼자 움직이는 것 + 카드와 비교 | 프로젝터 비교 | 표본 5 |

| 37~41 | 정리·신호 | 전체 | 체크표 |

### 단계별

- **만들기**: **`시계·타이머`** 동기화. 완성: **"아무것도 안 눌렀는데 숫자가 바뀌죠? 컴퓨터가 혼자 반복하는 거예요. 1초마다, 계속."** 지루한 아이는 다 한 사람 카드 대신 **`디지털 수족관`** 하나 더(보조 허락).

- **고치기**: 칠판 문장 베끼기. 결과에서 "뭐가 반복돼요?"
- **정리·신호**: **"계속 혼자 움직여요, 반복이에요"** 짝에게, 반복되는 곳 짚으며.

### 하지 말 것
- 초 단위 시간 수업으로 · 게임 유형(조건이 섞임)

### 막힐 때
| 상황 | 하기 |
|---|---|

## 5회차 — 우리 말로 만들기: 짝 계획서 하나

**한눈에** 새 개념 없음(5개 합치기) · `더 키우기` → **`만들기` 4칸을 짝이 한 장** · 짝 서술형 작품 1개
**정직한 목표** 1학년은 개인 서술형 작품을 만들지 않습니다. 1학년의 목표는 **"말로 계획하기"**(①②③을 말로). 3학년(또는 2학년 짝)이 치고, 1학년이 말하고 확인합니다. 3학년만 있는 짝은 각자 한 장씩.

### 선처리 추가분
- 짝별로 **종이 계획서**(이름/생김새/사용법/①②③ 칸) 1장 · 칠판: 4칸 예시 문장 하나("이름: 동물 퀴즈 / ① 문제가 보여요 / ② 답을 누르면 정답인지 나와요 / ③ 만약 다 맞히면 '최고!'")
- 다 한 사람 카드 ①"③ 만약 칸에 하나 더" ②"② 칸에 '계속' 넣기" ③"생김새 칸에 색 하나 더"

### 진행표
| 분 | 단계 | 메인 | 보조 |
|---|---|---|---|
| 0~3 | 열기 — 도감 5 | 전체 | 재배치 |
| 3~9 | 몸놀이 — 내 계획 말로 하기(짝 종이) | 손가락 셋 진행 | 순회(1학년 말하기 돕기) |
| 9~14 | `더 키우기` 열기 | 프로젝터 시범 | 순회 |
| 14~30 | 4칸 채우고 만들기 | "몇 번 칸?" 신호 | 순회·실패 |
| 30~37 | 찾기 — 종이 ↔ 화면 ○△, 두 칸 고치기 | 시범 | 표본 5 |
| 37~41 | 정리·신호 | 전체 | 체크표 |

### 단계별
- **몸놀이(짝 종이)**: 기기 손 떼고. 메인이 손가락 셋: **"먼저 뭐가 보여요?(①) 그다음 뭐 해요?(②) 만약 ~하면?(③)"** 짝의 말하는 사람이 답하고 읽는 사람이 종이에 그대로 적음. **"이게 계획서예요. 컴퓨터한테 주는 편지."**
- **더 키우기**: 메인 프로젝터: `내 작품` → 작품 → **`더 키우기`** → `만들기` 화면에 일부 채워짐. **"골랐던 게 글로 바뀌었죠? 이제 우리 말을 더 넣어요."** 짝은 읽는 사람 계정으로.
- **4칸**: 메인이 칸 이름을 하나씩 부르며 진행: **"1번 칸 `프로그램 이름` — 적었으면 손 머리."** → `어떻게 생겼나요?` → `어떻게 사용하나요?`(**"이건 입력 칸"**) → `① 먼저`(**"순서 칸"**) → `② 그다음` → `③ 만약`(**"조건 칸"**). 반복은 ②에 "계속/~마다". **"여러분이 쓴 문장이 그대로 프로그램이 돼요. 틀려도 돼요."** → 만들기.
- **찾기**: 종이 칸을 하나씩 읽고 화면에서 됐는지 **확인하는 사람(1학년)이 ○△**. △는 고치기 **두 칸**(`지금은 이래요`=△ 내용 / `이렇게 되면 좋겠어요`=원래 문장). 메인 시범 1회.
- **정리·신호**: **"우리가 쓴 대로 됐어요"** + ①②③ 중 하나 짚으며 배지 이름. "다음 시간은 자랑하는 날."

### 하지 말 것
- 아이 문장을 어른이 '좋은 문장'으로 · 4칸 강요(이름+①만 있어도 됨) · 1학년에게 개인 작품 강요

### 막힐 때
| 상황 | 하기 |
|---|---|
| 뭘 만들지 못 정함 | `더 키우기`로 (빈 계획서 주지 않기) |
| 결과가 많이 다름 | "어디를 못 알아들었을까?" → 그 칸을 짧게 → 두 칸 고치기 |
| 3학년만 치고 1학년 놂 | 보조가 1학년에게 종이·연필 주고 ○△ 역할 확인 |

## 6회차 — 자랑하기: 게시 · 갤러리 워크 · 도감

### 단계별
- **세 문장**: **"내 작품 이름은 ○○ / 이걸 누르면 ○○이 나와요 / 만약 ○○이면 ○○(또는 ○○이 계속 움직여요)."** 짝에게 1회씩.
- **별명 + 올리기**: 메인 시범: `내 작품` → 작품 → **`자랑하기`**(골라서 만들기 작품) 또는 **`게시판에 올리기`**(만들기 작품) → 게시판 **우리 반** → 별명(처음이면 여기서 정함)·제목 → 올리기. **"별명은 게시판에서 너를 부르는 이름. 나쁜 말은 컴퓨터가 안 받아요."** 짝 작품은 읽는 사람 계정에서 작성자 이름에 **둘 다**("민지·서준"). "쓸 수 없는 말이에요"가 뜨면 문구에 **어느 칸의 어떤 말**인지 나옴 → 그 말만 바꿈(보조).
- **갤러리 워크**: 메인 **"창가 줄은 자리에서 자기 작품을 열고 설명하는 사람, 복도 줄은 돌아다니는 사람. 돌아다니는 사람은 '어디가 입력이야?' 하고 묻고, 답을 들어야 좋아요를 눌러요."** 6분 후 **"로봇 정지! 교대!"** 좋아요는 자기 기기 `게시판`에서 그 작품을 열어 누름.
- **공유하기 + 도감**: 메인 프로젝터로 `공유하기` → **"이게 QR이에요. 집에는 선생님이 알림장으로 주소를 보내요."** → `개념 도감` → **"다섯 개 다 모았어요? 짝에게 하나씩 짚으면서 이름 말해요."** 비어 있으면 "어느 작품에서 만났더라?" 짝과 찾기.
- **수료**: **확인 신호: 도감 5칸 짚으며 이름 + 하나를 자기 작품으로.** 멘트: **"이제 컴퓨터한테 순서대로 시키고, 말 걸고, 반복시키고, 만약을 넣을 줄 알아요. 이게 프로그램 만드는 거예요."**
