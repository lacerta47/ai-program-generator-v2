# LUN 흥미 입문 과정 — 골라서 만들기

**대상** 초등 1~4학년 (컴퓨터 처음인 아이 포함) · **분량** 45분 × 4블록 = 3시간(핵심) + 1시간(확장)
**형태** 정규 4차시 / 반나절 특강 / 방과후 2주 · **기능** `골라서 만들기` 중심(선택형 — 긴 글쓰기 없음)

---

## 한 장 요약

### 여정 — 네 개의 동사

```
   1블록           2블록              3블록            4블록(선택)
  만들다     →    바꾸다       →    보여주다     →    이어받다
  [순서]          [입력·출력·반복]    [조건]            [5종 적용]
  생성 2회         생성 2회           게시 2개           생성 1회
```

- **3시간(1~3블록)으로 완결** — 개념 5종이 모두 등장합니다
- 4블록은 확장 — 문장 입력(타이핑)이 필요해 **3~4학년 권장**
- 아이가 쓰는 용어는 화면 배지의 두 글자뿐: `순서` `입력` `출력` `반복` `조건` (알고리즘·변수·함수 금지)

### 시간의 모양 — 어디에 시간이 실리는가

| 블록 | 45분의 구성 (★ = 개념 학습 장면) |
|---|---|
| 1 | 시작 4′ · 로그인 8′ · **만들기 14′** · 자랑 6′ · **★순서 8′** · 버퍼 4′ · 정리 1′ |
| 2 | 열기 3′ · **만들기 8′** · **★비교 7′ · ★배지 5′** · **만들기 11′** · **★반복 7′** · 정리 4′ |
| 3 | 도입 3′ · 별명 5′ · **게시 8′** · **★조건 13′ · ★내 작품 5′** · 좋아요 8′ · 정리 3′ |
| 4 | 도입 4′ · 고르기 6′ · **바꾸기 16′** · **★이름 붙이기 7′** · 도감 9′ · 마무리 3′ |

읽는 법 — 매 블록이 같은 리듬입니다: **만들고 → 만든 것 위에서 개념(★) → 나누고 정리**. 개념을 먼저 설명하는 장면은 없습니다.

### 약속하는 것 / 않는 것

| 되는 것 | 안 되는 것 (주장하지 않음) |
|---|---|
| 전원이 **스스로 고른 내용으로 동작하는 프로그램 완성** | 코딩 능력·문법 습득 (코드를 한 줄도 안 씀) |
| 개념 5개를 **자기 작품 위에서 만나 이름 붙이기** | 반복·조건의 완전한 습득·전이 — 그건 정규 12차시의 몫 |
| `순서` `입력` `출력`은 **자기 말 설명**까지 | AI 생성 품질 보장 — 가끔 실패함 → **실패 대응이 지도법에 포함** |
| "또 하고 싶다" — 1차 목표 | |

### 도달 기준 — 3수준으로 확인

| 수준 | 기준 | 예(`순서`) |
|---|---|---|
| **1 따라 말하기** | 정리 문장을 따라 말한다 | "차례대로 움직여요" |
| **2 지목** | 화면에서 짚는다 | 로직 카드 ①②를 짚음 |
| **3 자기 말** | 자기 작품으로 설명한다 | "먼저 버튼이 보이고, 누르면 글자가 나와요" |

**현실적 목표** — `순서`·`입력`·`출력`: 전원 2, 절반 이상 3 / `반복`·`조건`: 전원 1~2 (**관찰 + 이름 붙이기까지**).
1~2학년은 전 개념 1~2수준이면 충분합니다. 3수준을 강요하지 마세요.

## 개념 카드 5장

각 카드 4줄: **한마디**(아이에게 그대로) · **발문**(가장 좋은 질문 하나) · **성공 신호** · **오해 주의**.

### `순서` — 목표: 자기 말 설명
- **한마디** "①먼저, ②그다음. 프로그램은 **차례대로** 움직여요."
- **발문** "②를 **먼저** 하면 어떻게 될까?" ← 뒤집어 물으면 또렷해짐
- **성공 신호** "먼저 버튼이 보이고, 그다음 누르면 글자가 나와요"
- **오해 주의** 화면 배치 순서 = 실행 순서라고 생각함 → **눌러서 확인**시켜 교정
- *뜻: 명령이 정해진 차례로 실행 · 위치: 작품 위 초록 상자(로직 카드) ①②③*

### `입력` — 목표: 자기 말 설명
- **한마디** "내가 프로그램에게 **알려주는 것** — 누르기, 적기, 고르기!"
- **발문** "네 작품에서 입력은 뭐야?"
- **성공 신호** "내가 노란색을 골라서 노란색이 나왔어요"
- **오해 주의** 키보드만 입력이라 생각함 → **고르는 것도 입력**
- *뜻: 사람이 프로그램에 주는 값·행동 · 위치: `입력` 배지, 설문 선택지, 작품 속 버튼*

### `출력` — 목표: 자기 말 설명
- **한마디** "프로그램이 나에게 **보여주거나 들려주는 것**이에요."
- **발문** "뭐가 보여? 뭐가 들려?"
- **성공 신호** "누르니까 '축하해요!'가 나왔어요"
- **오해 주의** 너무 당연해서 그냥 넘어감 → **입력과 짝**으로 물어야 개념이 선다
- *뜻: 프로그램이 내보내는 결과 전부(화면·글자·소리) · 위치: `출력` 배지, 실행 화면*

### `반복` — 목표: 관찰 + 이름 붙이기
- **한마디** "같은 일을 **계속 되풀이해요.** 매번 다시 만들지 않아도 돼요!"
- **발문** "**아무것도 안 눌렀는데** 뭐가 움직여?"
- **성공 신호** "물고기가 계속 헤엄쳐요" (짚으면 충분)
- **오해 주의** 여러 번 누르는 걸 반복이라 함 → **손대지 않아도** 되풀이되는 것
- *뜻: 같은 동작의 되풀이 · 위치: `반복` 배지, 수족관 물고기, 타이머 숫자*

### `조건` — 목표: 찾기 + "~하면" 말하기
- **한마디** "**만약 ~하면 ~해요.** 상황에 따라 다른 일이 일어나요."
- **발문** "**언제** 그렇게 돼?" ← What이 아니라 **When**
- **성공 신호** "10점이 **되면** 축하가 나와요"
- **오해 주의** 결과만 말함("축하가 나와요") → **"언제?"**를 되물어 조건부를 끌어냄
- *뜻: 상황 판단으로 실행이 갈라짐. 다섯 중 가장 어렵고 가장 중요 · 위치: `조건` 배지, 퀴즈 정답/오답, 점수 도달, 타이머 0초*

## 수업 전 준비

### 전날, 수업할 교실에서 10분 점검 — 이게 수업의 절반입니다

1. **학생 계정으로 로그인 1회** — 학교 방화벽이 보안 확인(reCAPTCHA)을 막는 사례가 실제로 있고 **당일엔 해결 불가** → 막히면 전날 운영자(연구소)에 연락
2. **생성 1회** 끝까지 — 1분 이상 걸리면 학교망 혼잡 → 수업은 분단별 시차 생성으로
3. 소리놀이 쓸 거면 헤드폰 확인 / 브라우저 시작 페이지에 사이트 등록

### 계정·한도

- 교사 콘솔 → 학생 만들기(학년·반·인원·공용 PIN) + **보호자 동의 확인** 체크
- 한도: **총량형 1인 10회** (실사용 5~8회 + 재시도 여유) · PIN은 수업 내내 판서

### 앱 특성 바로알기 — 잘못 알기 쉬운 4가지

1. **좋아요는 자기 작품에도 눌립니다** → "내 것 말고 친구 것에만"은 **약속으로** 지도
2. **"처음!" 축하는 기기 기준** → 공용 컴퓨터실에선 안 뜰 수 있음(안 떠도 정상)
3. **학생 게시는 자기 반 게시판에만** → 반 밖에 안 보임. "친구들" = 우리 반
4. 이어서 만들기 = 작품 상세의 **갈래 모양 아이콘**. 자기 작품엔 버튼이 없음

# 1블록 — 만들다 · `순서`

> **목표** 프로그램을 완성해 실행하고, 차례대로 움직인다는 것을 안다.
> **모양** 시작 4′ · 로그인 8′ · 만들기 14′ · 자랑 6′ · **★순서 8′** · 버퍼 4′ · 정리 1′

| 분 | 단계 | 교사 한마디 · 봐야 할 것 |
|---|---|---|
| 0~4 | 시작 선언 | "오늘 **진짜 프로그램**을 만들 거예요. 바로 시작!" — 코딩·컴퓨터 설명 금지 |
| 4~12 | 로그인 | PIN 판서 · 도우미 짝. 늦는 아이는 **버퍼로 미루고 진행** |
| 12~22 | 만들기 | "첫 작품은 **소개 카드**"(교사 지정은 이번뿐) → "정답 없어요, 마음에 드는 걸!" |
| 22~26 | 생성 | **분단별 시차**로 '만들기' · 실패 문구엔 "컴퓨터가 실수했대! 다시 눌러 보자" |
| 26~32 | 실행+호명 | **전원 이름 불러 감탄** — 침묵이 흥미를 반으로 줄임 |
| 32~40 | **★로직 카드** | 아래 장면 |
| 40~44 | 버퍼 | 두 번째 작품 *또는* 늦은 아이 따라잡기 |
| 44~45 | 정리 | "프로그램은 **차례대로** 움직여요" 다 같이 따라 말하기 |

### ★ 장면: 로직 카드 (32~40분)

**진행** 작품 위 초록 상자 ①②③이 교재. ①을 소리 내어 읽게 → **"진짜 그런지 눌러 볼까?"** → 자기 화면에서 확인(수준 2) → ②③ 반복 → **"②를 먼저 하면 어떻게 될까?"** → "①먼저 ②그다음, 이게 **순서**" → 배지에서 `순서` 찾기.
**왜** 교사가 풀어 설명하면 남지 않습니다. 카드는 이미 저학년 어휘 — **아이가 읽고, 눌러 확인**해야 자기 것이 됩니다. 읽기 어려운 아이는 교사가 읽어 주되 화면을 손으로 짚으며 대조.

### 장면: 생성 실패 (언제든)

**진행** "앗, 만든 프로그램이 잘 움직이지 않아요"가 뜨면 → **"컴퓨터가 실수했대! 다시 눌러 보자."**
**왜** 아이 잘못이 아님을 즉시 분명히. 재시도는 거의 성공합니다.

**⚠ 밀리면** 버퍼를 통째로 쓰세요. **로직 카드는 줄이지 마세요** — 이 블록의 학습이 전부 거기 있습니다.
**⚠ 막히면** 로그인 실패(소수)=교사가 대신 입력 / 선택 망설임="둘 중 뭐가 더 좋아?" / 결과 불만="다음에 바꾸는 법 배워, 오늘 건 오늘의 작품!"

# 2블록 — 바꾸다 · `입력` `출력` `반복`

> **목표** 고른 답이 다르면 결과가 달라짐을 알고, 저절로 되풀이되는 움직임을 관찰한다.
> **모양** 열기 3′ · 만들기 8′ · **★비교 7′ · ★배지 5′** · 만들기 11′ · **★반복 7′** · 정리 4′

| 분 | 단계 | 교사 한마디 · 봐야 할 것 |
|---|---|---|
| 0~3 | 지난 작품 열기 | "아까 만든 거 기억나?" |
| 3~11 | 같은 유형·다른 답 | "이번엔 **짝과 다르게** 골라 보자" |
| 11~18 | **★짝 비교** | 아래 장면 |
| 18~23 | **★배지 확인** | **아이가 직접 눌러** 설명 읽기 → "네 작품에서 입력은? 출력은?" |
| 23~34 | **★반복 미션** | "혼자 움직이는 걸 만들어 봐요 — 셋 중 하나!" |
| 34~41 | **★반복 발견** | "아무것도 안 눌렀는데 뭐가 움직여?" → 화면 짚기 |
| 41~45 | 정리 | "오늘 얻은 개념 셋 — 입력·출력·반복!" |

### ★ 장면: 짝 비교 → 입력·출력 (11~23분)

**진행** 짝과 화면을 나란히 → "같은 카드인데 **왜 다르지?**" → "고른 게 달라서요" → "똑같이 고르면?" → "똑같이 나와요" → 고른 것 = `입력`, 나온 화면 = `출력` (배지를 아이가 눌러 읽기) → **"네 작품에서 입력은 뭐야? 출력은 뭐야?"**
**왜** 마지막 질문에서 수준 3이 나옵니다. 배지 설명을 교사가 대신 읽으면 효과가 반감됩니다.

### ★ 장면: 반복 미션 (23~41분)

**진행** 미션 — "손대지 않아도 **혼자 움직이는 걸** 만들어 봐요": **디지털 수족관**(권장) / **시계·타이머** / **소리놀이**(헤드폰 있을 때만). 완성 후 "아무것도 안 눌렀는데 **뭐가 움직여?**" → 짚기 → "같은 걸 계속 되풀이하네 — **반복**!"
**왜** 자유 선택이 아니라 셋으로 좁힌 이유: 고르다 시간이 새고, 어려운 유형(게임·미로)을 골라 실패하는 아이가 나오고, 학습 초점이 흩어집니다.
**대체 경로** 내 작품에 `반복` 배지가 없으면(드물게 있음) 틀렸다 하지 말고 **교육테스트 보드의 수족관 예시**로 관찰 계속.

**⚠ 밀리면** 미션 유형 안내를 생략하고 전원 수족관 통일(3분 절약). 짝 비교는 줄이지 마세요.
**⚠ 막히면** 짝과 답이 같음="하나만 바꿔 볼까?" / 유형 못 고름=수족관 지정.

# 3블록 — 보여주다 · `조건`

> **목표** 남의 작품에서 조건을 찾아 그 상황을 직접 만들어 확인하고, 내 작품 2개를 게시한다.
> **모양** 도입 3′ · 별명 5′ · 게시 8′ · **★조건 13′ · ★내 작품 5′** · 좋아요 8′ · 정리 3′

| 분 | 단계 | 교사 한마디 · 봐야 할 것 |
|---|---|---|
| 0~3 | 도입 | "오늘은 친구들한테 보여줄 거예요" |
| 3~8 | 별명 | "`무지개손`처럼 멋진 별명!" — **본명 금지** |
| 8~16 | **게시 2개** | 카드 + 반복 작품 둘 다 — **도감·격자의 재료**. "핵심 한 줄"은 선택(30초만) |
| 16~29 | **★조건 보물찾기** | 아래 장면 |
| 29~34 | **★내 작품에 조건?** | 있으면 "언제 그렇게 돼?" / 없으면 "다음에 만들어 볼까?" — 없는 게 잘못 아님 |
| 34~42 | 좋아요 | "친구 것 **3개 이상**, 내 것 말고 — **약속**!" · 순위 발표 금지 |
| 42~45 | 정리 | "만약 ~하면 ~한다 — 조건!" |

### ★ 장면: 조건 보물찾기 (16~29분)

**진행** 게시판 검색줄 아래 `조건` 배지를 눌러 작품만 모아 보기 → 미션 "**실제로 그 일이 일어나게 해보기!**"

> 찾기 → **예측** "언제 뭐가 달라질 것 같아?" → **실행** "그렇게 되게 해봐" → 확인 "맞았어?" → 정리 "**만약 ~하면 ~한다**"

**왜** 찾는 데서 끝내면 개념이 남지 않습니다 — **실행이 심장**입니다. 퀴즈 정답/오답·게임 점수·타이머 0초가 찾기 쉽습니다. 2개 못 찾아도 됨: **1개를 제대로**가 낫습니다.

### 게시 2개를 하는 이유 (8~16분)

개념 도감과 교사 격자는 **게시한 작품만** 집계합니다. 카드(순서·입력·출력)와 반복 작품(반복, 종종 조건)을 둘 다 올려야 4블록 도감과 수업 후 격자가 의미를 가집니다. "처음!" 축하가 뜨면 크게 반응(공용 PC에선 안 뜰 수 있음 — 정상).

**⚠ 밀리면** 내 작품 조건 확인(29~34)을 줄이세요. **보물찾기의 실행은 줄이지 마세요.**
**⚠ 막히면** 별명 검열에 걸림="그 말은 쓸 수 없대, 다른 멋진 걸로!" / 조건 못 찾음=타이머로 유도("0초가 되면?").

# 4블록(확장) — 이어받다 · 5종 적용 *(3~4학년 권장)*

> **목표** 친구 작품을 이어받아 **한 가지만** 바꾸고, 그 변화가 어느 개념인지 말한다.
> **모양** 도입 4′ · 고르기 6′ · 바꾸기 16′ · **★이름 붙이기 7′** · 도감 9′ · 마무리 3′
> **주의** 이 블록만 문장 입력(타이핑)이 필요 — 1~2학년은 생략하고 3블록에서 마치는 것을 권장

| 분 | 단계 | 교사 한마디 · 봐야 할 것 |
|---|---|---|
| 0~4 | 도입 | "친구 작품을 **빌려서** 바꿀 수 있어요 — 원작자 이름이 남아요" |
| 4~10 | 고르기 | **갈래 아이콘** = 이어서 만들기 · "좋아요 없는 작품도 보물이야" |
| 10~26 | 한 가지 바꾸기 | 바꿀 것을 **말로 정하고 → 그 문장을 그대로 입력** |
| 26~33 | **★이름 붙이기** | "네가 바꾼 건 다섯 개 중 뭐야?" |
| 33~42 | 도감 | "다섯 개 중 몇 개 모았어?" — 개수 경쟁 금지 |
| 42~45 | 마무리 | "**이게 다 네가 만든 거야**" + 원작자에게 고맙다고 말하기 |

### ★ 장면: 바꾼 것에 개념 이름 붙이기 (26~33분)

| 바꾼 것 | 개념 |
|---|---|
| 색깔·모양 | `출력` |
| 버튼 추가 | `입력` |
| 끝나는 점수 | `조건` |
| 더 빨리·계속 | `반복` |
| 나오는 차례 | `순서` |

**진행** "네가 바꾼 건 이 다섯 중 뭐야?" — 정확히 못 맞혀도 통과. **다섯 중에서 고르려고 생각하는 것** 자체가 목표.
**타이핑 지원** 느린 아이는 짝·교사가 대신 입력 — 문장을 정한 건 아이입니다. **딱 한 가지만**: 여러 개를 바꾸면 무엇 때문에 달라졌는지 알 수 없습니다(이게 나중에 배울 고치기의 기초).

## 도달 확인 — 기록하지 않는 확인

블록 끝 손들기·한 마디만. 기록·점수화하지 않습니다(평가가 되는 순간 놀이가 과제가 됩니다).

| 블록 | 질문 | 통과 |
|---|---|---|
| 1 | "①다음엔 뭐가 됐지?" | ②를 말함 |
| 2 | "왜 짝이랑 다르게 나왔지?" / "뭐가 혼자 움직였어?" | "고른 게 달라서" / 짚기 |
| 3 | "언제 그렇게 됐어?" | "~하면" 형태 |
| 4 | "바꾼 건 다섯 중 뭐야?" | 고르면 통과(틀려도) |

**교사 격자 주의** — 격자는 **게시한 작품만** 집계. 이 과정(게시 2개)대로면 보통 3~4개가 잡힙니다. **0~1개인 아이는 "개념을 못 얻은 아이"가 아니라 "게시를 못 한 아이"일 가능성부터** 확인. 진짜 평가는 마지막 질문 하나:

> **"또 하고 싶은 사람?"**
