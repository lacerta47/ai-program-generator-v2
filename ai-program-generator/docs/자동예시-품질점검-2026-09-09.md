## 부수 발견

- **495/899(55%)가 localStorage를 사용**하고 488건이 try/catch로 보호돼 오류는 안 나지만, 미리보기 sandbox에서는 저장이 **한 번도 성공하지 않음**. "기록 저장" 기능이 있는 척만 하는 작품이 절반이라는 뜻. 사용자 작품도 같은 조건. → 프롬프트에서 storage를 금지하고 "새로고침하면 사라져요"를 전제로 만들게 하는 편이 정직함.
- 정적 게이트(7/24)와 주석 삼킴 차단(8/3)은 효과 확실 — 그 이후 정적 실패 0.

## 권장 조치 (우선순위)

1. **게이트 확장**(`lib/ai/validateCode.ts`): 미정의 함수·변수 호출, 리터럴 클래스 셀렉터 대조 → 실행 오류 54건 중 22건(41%) 사전 차단. 단위 테스트 있음.
2. **프롬프트 2줄**(`lib/ai/prompts.ts`): function 선언 사용·호출은 하단 / storage 대체물은 메서드 포함 객체(또는 storage 금지).
3. **자동예시 유형 가중치**: 그림판을 fast 모드에서 제외하거나(일반 모드로) 뽑힐 확률 낮춤.
4. 7월 정적 실패 11건 + 실행 불가 4건은 **삭제**(auto-example-bot 소유라 안전).
5. Web Audio 6건은 실제 클릭으로 재검증 후 판단.
